The Math Inside Attention

Mathematics Transformers

Feb 27, 2026

The transformer's central operation fits on one line:

Attention(Q, K, V) = softmax(Q·Kᵀ / √dₖ) · V

It looks dense, but each piece has a clear job. Reading it slowly is one of the best ways to understand what a transformer does.

Queries, Keys and Values

Each token's vector is multiplied by three learned matrices to produce three new vectors:

  • Query: what this token is looking for.
  • Key: what this token offers to others.
  • Value: the information this token passes on if it is attended to.

The analogy to a search engine is loose but helpful. A query is compared against every key; good matches retrieve the corresponding values.

Scores From Dot Products

Q·Kᵀ computes the dot product between every query and every key, giving a score matrix with one row per token and one column per token it can look at. A high score means the query and key point in similar directions.

For n tokens this matrix is n × n, which is why attention cost grows quadratically with sequence length.

Why Divide by √dₖ

If query and key components have roughly unit variance, their dot product over dₖ dimensions has variance around dₖ. With dₖ = 128, typical scores would be large, and softmax over large values saturates: one score takes almost all the probability and gradients become vanishingly small.

Dividing by √dₖ brings the variance back to about 1, keeping softmax in a range where it can learn.

The square root is not decoration. Without it, deep transformers train poorly.

Softmax, Then Mix

Softmax across each row turns scores into weights that sum to one. The output for each token is the weighted average of all value vectors, using those weights.

In decoder models, a causal mask sets scores for future tokens to minus infinity before softmax, so each token can only attend to itself and earlier positions.

Many Heads

Multi-head attention runs this operation several times in parallel with smaller dimensions, each head with its own projection matrices. Different heads can specialise, such as tracking syntax, nearby words or long-range references, and their outputs are concatenated and projected back.

Closing Thought

Attention is a learned, differentiable lookup: every token decides how much to listen to every other token. Almost everything else in a transformer exists to support this one step.
