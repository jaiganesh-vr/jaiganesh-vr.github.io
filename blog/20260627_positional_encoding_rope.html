Positional Encoding and RoPE

Mathematics Transformers

Jun 27, 2026

Attention compares every token with every other token, but nothing in the operation itself knows which token came first. Without extra information, "dog bites man" and "man bites dog" look identical. Positional encoding supplies that missing order.

Absolute Positions

The original transformer added a fixed vector to each token embedding, built from sine and cosine waves of different frequencies. Each position gets a unique pattern, and nearby positions get similar patterns.

Later models often learned these position vectors instead. Both approaches share a limitation: they encode where a token is, while language mostly cares about how far apart tokens are.

Rotary Position Embedding

RoPE takes a different approach. Instead of adding position to the embedding, it rotates the query and key vectors by an angle that depends on position.

  • Each query and key vector is split into pairs of dimensions.
  • Each pair is treated as a point in 2D and rotated by angle m·θᵢ, where m is the position.
  • Different pairs use different frequencies θᵢ, from fast to slow.

Why Rotation Works

The key property comes from how rotations interact with dot products. If a query at position m and a key at position n are both rotated, their dot product depends only on the difference m − n.

Rotate both vectors by their positions, and attention sees only the distance between them.

That gives relative position information for free, without any extra parameters, and it applies inside the attention score itself, exactly where order matters.

The mix of frequencies also helps. Fast-rotating pairs distinguish nearby positions; slow-rotating pairs vary gently across long distances, so the model can track both local and long-range structure.

Extending Context

Models only see positions up to their training length. RoPE made extending context more tractable, because the rotation frequencies can be rescaled. Techniques such as position interpolation and NTK-aware scaling stretch the angles so longer sequences fall within the range the model learned, usually with a short round of extra training.

Closing Thought

RoPE is an elegant piece of geometry: order becomes rotation, and relative distance falls out of the dot product. It is a large part of why most modern language models handle long contexts at all.
