Low-Rank Matrices and SVD

Mathematics Linear Algebra

Jul 21, 2026

Many ideas in modern machine learning, from LoRA to model compression to embedding analysis, rely on one observation: large matrices often contain much less information than their size suggests. Rank and the singular value decomposition are the tools for seeing that.

What Rank Means

The rank of a matrix is the number of independent directions its rows or columns span. A 1,000 × 1,000 matrix can have rank up to 1,000. If its rank is 10, every row is a combination of just 10 underlying patterns.

A low-rank matrix can be written as a product of two thin matrices:

M (m × n) = A (m × r) · B (r × n)

Storing A and B takes r·(m + n) numbers instead of m·n, which is a large saving when r is small.

The Singular Value Decomposition

Any matrix can be factored as:

M = U · Σ · Vᵀ

  • U and V are rotations: their columns are orthonormal directions.
  • Σ is diagonal, holding the singular values, sorted from largest to smallest.

Each singular value measures how much the matrix stretches along one pair of directions. Large values are the main structure; small values are fine detail or noise.

Best Low-Rank Approximation

Keeping only the top k singular values and their directions gives a rank-k matrix. The Eckart–Young theorem says this is the best possible rank-k approximation, in the sense of minimising the squared error.

If the singular values fall off quickly, a few directions capture almost everything.

Where It Shows Up

  • LoRA: weight updates are learned directly in low-rank form, B·A, on the assumption that task adaptation needs few directions.
  • Compression: large weight matrices can be replaced by truncated SVD factors to reduce size.
  • PCA: principal component analysis is SVD on centred data, used to visualise and reduce embeddings.
  • Recommendation systems: user-item matrices are modelled as low-rank, with each user and item described by a few latent factors.

Closing Thought

Rank is a measure of how much is really going on inside a matrix. A lot of practical efficiency in machine learning comes from noticing that the answer is often far less than the dimensions suggest.
