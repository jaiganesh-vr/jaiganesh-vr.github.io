Backpropagation Is Just the Chain Rule

Mathematics Training

Sep 07, 2026

Training needs the gradient of the loss with respect to every parameter in the network. For a model with billions of parameters, computing each one separately would be hopeless. Backpropagation computes all of them in a single backward pass, at roughly the cost of one forward pass.

Underneath, it is the chain rule from calculus, applied systematically.

The Chain Rule

If y depends on u, and u depends on x, then:

dy/dx = (dy/du) · (du/dx)

A neural network is a long chain of such dependencies: inputs feed layer one, which feeds layer two, and so on until the loss. The gradient of the loss with respect to any weight is a product of local derivatives along the path from that weight to the loss.

Computational Graphs

Frameworks represent a model as a graph of simple operations: matrix multiplies, additions, activation functions. Each operation knows two things:

  • How to compute its output from its inputs, for the forward pass.
  • How to turn the gradient of its output into gradients of its inputs, for the backward pass.

The Two Passes

  • Forward: compute every operation from inputs to loss, storing intermediate values.
  • Backward: start with the gradient of the loss with respect to itself, which is 1, and walk the graph in reverse. Each operation receives the gradient of its output and passes gradients back to its inputs.

When a value feeds into several operations, the gradients flowing back from each are summed.

Going backward lets every shared intermediate result be reused, which is what makes it efficient.

Why Backward, Not Forward

The network has one output, the loss, and billions of inputs, the parameters. Working backward from the single output computes all the gradients at once. Working forward would require a separate pass per parameter. This is reverse-mode automatic differentiation.

The Memory Trade-off

The backward pass needs intermediate values from the forward pass, so they must be kept in memory. For large models, these activations can use more memory than the weights. Activation checkpointing saves only some of them and recomputes the rest during the backward pass, trading compute for memory.

Closing Thought

Backpropagation is not a learning algorithm in itself. It is an efficient way to answer one question: which direction should every parameter move? The optimizer decides how far.
