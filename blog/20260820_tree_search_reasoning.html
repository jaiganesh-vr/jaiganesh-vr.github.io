Tree Search for Reasoning

Algorithms Reasoning

Aug 20, 2026

A language model normally reasons in a single straight line: one step after another, with no way back. Search algorithms offer an alternative, exploring several lines of reasoning and keeping the most promising. It is an old idea from game-playing AI applied to a new kind of state.

Reasoning as a Tree

Treat each partial solution as a node. From any node, the model can propose several possible next steps, each creating a child node. A complete solution is a path from the root to a leaf.

Two ingredients make search possible:

  • A generator: the model proposes candidate next steps.
  • An evaluator: something scores how promising a partial path is, such as the model itself, a trained value model or an external check.

Tree of Thoughts

Tree of Thoughts applies breadth-first or depth-first search over reasoning steps. At each level, the model generates several thoughts, rates them, and continues only the best. Dead ends are abandoned and the search backtracks.

On puzzles that need planning or trial and error, this beats single-pass reasoning by a wide margin.

Monte Carlo Tree Search

MCTS, famous from game-playing systems like AlphaGo, balances exploration and exploitation:

  • Select: walk down the tree, preferring nodes with high value or few visits.
  • Expand: add a new child step at the frontier.
  • Evaluate: estimate the value of the new node, by a value model or by completing the solution.
  • Backpropagate: update value estimates along the path.

Search spends extra compute where it is most likely to change the answer.

Verifiers Make or Break It

Search is only as good as its evaluator. Where answers can be checked, such as code with tests or maths with known solutions, search can be very effective. Where they cannot, a model judging its own partial reasoning may confidently prefer wrong paths.

Process reward models, trained to score individual reasoning steps rather than final answers, were developed partly to provide that signal.

Explicit Search vs Learned Reasoning

Reasoning models trained with reinforcement learning now perform a kind of implicit search within one long chain of thought, backtracking in text. Explicit tree search remains useful when strong verifiers exist and when the budget allows many parallel attempts.

Closing Thought

Search turns a model's ability to propose ideas into an ability to explore them. As with game-playing, the combination of a good proposer and a good evaluator is stronger than either alone.
