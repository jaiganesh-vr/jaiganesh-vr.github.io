Context Engineering

AI Agents LLMs

Jul 09, 2026

Prompt engineering was about finding the right words for an instruction. As applications grew into agents that run for many steps, the question changed. What matters now is everything in the context window at each step: instructions, history, retrieved documents, tool definitions and tool results.

Deciding what goes in, and what stays out, is context engineering.

Why This Matters

A model can only use what it can see. Most agent failures that look like reasoning problems are context problems: the relevant fact was never retrieved, was buried under irrelevant output, or was summarised away three steps earlier.

The model's answer is only as good as the context you assembled for it.

Context Is a Budget

Long context windows make it tempting to include everything. But models attend less reliably to information in the middle of very long contexts, every extra token costs money and latency, and irrelevant material actively distracts.

Treat the window as a budget to spend, not a container to fill.

What Goes Into Context

  • System instructions: clear, specific and organised, with the why behind important rules.
  • Tool definitions: a focused set, with descriptions that explain when to use each.
  • Retrieved knowledge: the few most relevant passages, not every match.
  • History: recent turns in full, older turns summarised.
  • Tool results: trimmed to the fields that matter.

Techniques That Help

  • Just-in-time retrieval: give the agent tools to look things up when needed, instead of loading everything upfront.
  • Compaction: when the context nears its limit, summarise progress and restart with the summary.
  • External notes: let the agent maintain a progress file or task list it can re-read.
  • Sub-agents: delegate exploratory work so only the conclusions return to the main context.

Structure Helps Too

Clear structure, such as labelled sections or XML-style tags separating instructions, documents and examples, helps the model distinguish what each part of the context is for. Putting long documents before the question, rather than after, often improves results.

Closing Thought

As models improve, the limiting factor shifts from what they can reason about to what they are given to reason with. Context engineering is where much of an agent's quality is now decided.
