Speculative Decoding

Algorithms Inference Systems

May 16, 2026

Generating text with a large model is slow mostly because each token needs a full forward pass, and those passes happen one after another. Speculative decoding breaks part of that sequence by letting a cheap model guess ahead and the expensive model check the guesses in bulk.

The Observation

During decoding, a large model is usually limited by memory bandwidth, not arithmetic. Loading the weights for one token costs almost the same as loading them to process several tokens at once. Verifying five proposed tokens in parallel takes about as long as generating one.

Many tokens are also easy to predict. After "the United", a small model guesses "States" just as well as a large one.

The Algorithm

  • A small, fast draft model generates the next k tokens, for example four.
  • The large target model processes all k proposed tokens in one forward pass, getting its own probabilities at each position.
  • Proposed tokens are accepted left to right as long as they pass a check against the target's probabilities.
  • At the first rejection, a replacement token is sampled from an adjusted distribution, and the rest of the draft is discarded.

Even when every proposal is rejected, the target's single pass still yields one new token, so progress is never slower than ordinary decoding apart from the draft overhead.

Why the Output Is Unchanged

The acceptance rule is a form of rejection sampling. Each draft token is accepted with probability min(1, p_target / p_draft), and rejections resample from the leftover probability mass. The result is provably distributed exactly as if the target model had generated every token itself.

Speculative decoding is a speed-up, not an approximation.

What Determines the Speed-up

The gain depends on the acceptance rate, which depends on how well the draft model agrees with the target. Code and structured text, which are highly predictable, often see larger speed-ups than creative writing. Two to three times faster decoding is commonly reported.

Variants

Some approaches skip the separate draft model: extra prediction heads on the target model propose several future tokens, or drafts come from matching n-grams already present in the prompt, which works well when output copies from input, as in code editing.

Closing Thought

Speculative decoding is a good reminder that inference speed is a systems problem. The model stays the same; only the way we schedule its work changes.
