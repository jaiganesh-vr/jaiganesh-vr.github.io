FlashAttention: Same Math, Less Memory Traffic

Algorithms GPU Systems

Jul 03, 2026

Attention's cost is usually described as quadratic in sequence length, and that is true for arithmetic. But on GPUs, the bigger problem was memory: standard implementations wrote the entire n × n attention matrix out to GPU memory and read it back several times.

FlashAttention computes exactly the same result without ever storing that matrix.

The Memory Hierarchy

A GPU has a small amount of very fast on-chip memory, called SRAM, and a large amount of much slower high-bandwidth memory. Moving data between them is often more expensive than the arithmetic performed on it.

A naive attention kernel computes scores, writes them to slow memory, reads them to apply softmax, writes the result, then reads it again to multiply by the values. For long sequences, that traffic dominates.

The bottleneck was not computing attention. It was moving it around.

Tiling

FlashAttention splits queries, keys and values into blocks small enough to fit in fast on-chip memory. For each block of queries, it loops over blocks of keys and values, computing partial results entirely on-chip, and writes only the final output back.

The n × n matrix is never materialised. Memory use becomes linear in sequence length instead of quadratic.

The Softmax Problem

Tiling seems impossible at first, because softmax needs the maximum and sum over an entire row of scores, and with tiling you only see one block at a time.

The solution is online softmax. As each new block arrives, the kernel keeps a running maximum and running sum, and rescales previously accumulated results whenever the maximum changes. After the last block, the result is mathematically identical to a full softmax.

What It Changed

  • Attention became several times faster in practice, with no approximation.
  • Memory savings made much longer context lengths practical to train.
  • The backward pass recomputes attention blocks instead of storing them, trading cheap arithmetic for expensive memory.

Later versions improved parallelism across GPU threads and took advantage of newer hardware features, and the approach is now standard in training and inference frameworks.

Closing Thought

FlashAttention did not change the model at all. It changed the order of operations to respect how hardware actually works, which is a recurring theme in making AI systems fast.
