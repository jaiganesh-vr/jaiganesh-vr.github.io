Layer Normalization and Residual Connections

Mathematics Transformers

Aug 14, 2026

Attention gets the credit, but a transformer with only attention and feed-forward layers would barely train once it got deep. Two simple components make depth work: residual connections and layer normalization.

Residual Connections

Instead of passing a vector through a layer and using only the output, a residual connection adds the layer's output back to its input:

x ← x + Layer(x)

This changes what each layer has to learn. It no longer has to reproduce the whole representation, only a correction to it.

It also fixes gradient flow. During backpropagation, the gradient has a direct path through the addition, skipping the layer entirely. Even in a model with a hundred layers, early layers receive a usable signal.

Think of the residual stream as a shared workspace that every layer reads from and writes to.

Layer Normalization

As vectors pass through many layers, their scale can drift: some dimensions grow large, others shrink, and training becomes unstable. Layer normalization rescales each token's vector independently:

  • Compute the mean and variance across the vector's dimensions.
  • Subtract the mean and divide by the standard deviation.
  • Multiply by a learned scale and add a learned shift.

After normalization, every token vector entering a layer has a predictable scale, which keeps activations and gradients well-behaved.

RMSNorm

Many modern models use RMSNorm, a simpler variant that skips mean subtraction and divides by the root mean square of the vector. It performs about as well, with less computation.

Pre-Norm vs Post-Norm

The original transformer normalized after the residual addition. Most modern models normalize before each sub-layer instead:

x ← x + Layer(Norm(x))

This pre-norm arrangement leaves the residual stream itself untouched, which makes very deep models far more stable to train and reduces the need for careful learning rate warm-up.

Closing Thought

Residuals and normalization rarely appear in diagrams with the same prominence as attention, but they are what allow a stack of layers to behave like one deep, trainable model.
