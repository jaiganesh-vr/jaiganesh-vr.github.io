Orthogonal Vectors and Subspaces

Mathematics Linear Algebra

Jul 16, 2022

Perpendicularity is the most useful geometric relationship in linear algebra. It extends from pairs of vectors to whole subspaces, and it explains how the spaces attached to a matrix are arranged.

Orthogonal Vectors

Two vectors are orthogonal when their dot product is zero. This is just the Pythagorean theorem in n dimensions:

‖x + y‖² = ‖x‖² + 2xᵀy + ‖y‖²

The middle term vanishes exactly when xᵀy = 0, leaving ‖x + y‖² = ‖x‖² + ‖y‖². Nonzero orthogonal vectors are also automatically independent. Dotting a zero combination with any one of them removes every term except its own, which forces its coefficient to be zero.

Orthogonal Subspaces

Two subspaces are orthogonal when every vector in one is perpendicular to every vector in the other.

This is stricter than it sounds. A wall and the floor of a room are not orthogonal subspaces, despite appearances, since the line where they meet lies in both and is not perpendicular to itself. Two orthogonal subspaces meet only at zero.

The Row Space and the Null Space

The equation Ax = 0 is a statement about orthogonality. Written out by rows, it says:

(row 1)ᵀx = 0, (row 2)ᵀx = 0, …, (row m)ᵀx = 0

So x is perpendicular to every row, and therefore to every combination of rows.

The null space is orthogonal to the row space. This comes straight from reading Ax = 0.

Their dimensions are r and n − r, which add to n. They are orthogonal complements: together they account for all of ℝⁿ, and any vector splits into a row space part and a null space part. Taking the same steps with Aᵀ shows that, in ℝᵐ, the column space is the orthogonal complement of the left null space, which contains the solutions of Aᵀy = 0.

For example, A = [[1, 2], [2, 4]] has a row space along (1, 2) and a null space along (2, −1). These are perpendicular lines that fill the plane.

What This Says About Solutions

Ax = b has a solution exactly when b is in the column space. By the complement relation, this is the same as b being perpendicular to every solution of Aᵀy = 0. That gives a clean test for solvability that does not need Ax = b to be solved.

The same reasoning also shows that AᵀA has the same null space as A. If AᵀAx = 0, then xᵀAᵀAx = ‖Ax‖² = 0, so Ax = 0. Therefore AᵀA is invertible exactly when A has independent columns, a fact that least squares depends on.

Orthonormal Bases

A basis of perpendicular unit vectors is the easiest kind to work with. Stacked as the columns of Q, they satisfy:

QᵀQ = I

If Q is square, this means Q⁻¹ = Qᵀ, so inversion costs nothing. Coordinates are simply dot products, since the coefficient of qᵢ in v is qᵢᵀv. Multiplying by Q also preserves lengths and angles, so it does not amplify rounding error.

Gram-Schmidt

Any independent set can be made orthonormal. Take the vectors in turn, subtract from each its components along the directions already found, and normalise what is left:

eₖ = aₖ − Σⱼ (qⱼᵀaₖ) qⱼ, then qₖ = eₖ / ‖eₖ‖ 

import numpy as np

def gram_schmidt(A):
    Q = np.zeros(A.shape, dtype=float)
    R = np.zeros((A.shape[1], A.shape[1]))
    for k in range(A.shape[1]):
        e = A[:, k].astype(float)
        for j in range(k):
            R[j, k] = Q[:, j] @ e    # recomputed on the remainder
            e -= R[j, k] * Q[:, j]
        R[k, k] = np.linalg.norm(e)
        Q[:, k] = e / R[k, k]
    return Q, R

A = np.array([[1, 1], [1, 0], [0, 1]])
Q, R = gram_schmidt(A)
print((Q.T @ Q).round(10))        # identity
print(np.allclose(Q @ R, A))      # True

The numbers subtracted along the way form an upper triangular matrix R, and this gives A = QR. It is the orthogonal counterpart of A = LU, in that it records a process for simplifying a matrix. Library routines usually compute QR with Householder reflections, which are numerically more reliable than Gram-Schmidt.

Closing Thought

Orthogonality reveals a matrix's subspaces to be a pair of perpendicular splits, one of its input space and one of its output space. The practical use of this appears when Ax = b has no exact solution, and the best we can do is drop a perpendicular.
