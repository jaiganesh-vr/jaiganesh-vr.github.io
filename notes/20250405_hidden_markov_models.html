Hidden Markov Models

Artificial Intelligence Probability

Apr 05, 2025

Many problems involve a state that changes over time and can only be observed indirectly: a speaker's intended words behind an audio signal, a robot's position behind noisy sensor readings. Hidden Markov models are the classic framework for this.

The Model

An HMM has a hidden state variable Xₜ and an observed evidence variable Eₜ at each time step. It is defined by:

  • Initial distribution: P(X₀).
  • Transition model: P(Xₜ | Xₜ₋₁), how the state evolves.
  • Sensor model: P(Eₜ | Xₜ), how observations relate to the state.

Two assumptions keep this tractable:

  • Markov assumption: the next state depends only on the current state, not the full history.
  • Sensor Markov assumption: each observation depends only on the current state.

A Simple Example

A security guard underground cannot see the weather but sees whether the director arrives with an umbrella. The hidden state is Rain; the evidence is Umbrella. Rain tends to persist from day to day, and umbrellas are much more likely on rainy days.

Four Inference Tasks

  • Filtering: what is the current state, given all evidence so far? P(Xₜ | e₁:ₜ)
  • Prediction: what will the state be in the future?
  • Smoothing: what was the state at some past time, given all evidence including later observations?
  • Most likely explanation: what sequence of states best explains the observations?

Filtering With the Forward Algorithm

Filtering is computed recursively. Each step predicts the next state using the transition model, then updates with the new observation using the sensor model:

f₁:ₜ₊₁ = α · P(eₜ₊₁ | Xₜ₊₁) · Σₓₜ P(Xₜ₊₁ | xₜ) · f₁:ₜ

The cost per step is constant in the length of the sequence, so an agent can track the state indefinitely.

Predict with the transition model, correct with the sensor model, repeat.

Smoothing

The forward-backward algorithm combines a forward pass over evidence up to time k with a backward pass over evidence after k, giving better estimates of past states than filtering alone.

The Viterbi Algorithm

The most likely state sequence is not the same as the sequence of individually most likely states. The Viterbi algorithm finds it with dynamic programming, keeping for each state the probability of the best path ending there. Its cost is linear in the length of the sequence.

Applications

HMMs powered speech recognition for decades, and are used in part-of-speech tagging, gene sequence analysis and handwriting recognition. Kalman filters apply the same ideas to continuous states, and particle filters approximate them with sampling.

Closing Thought

Hidden Markov models capture a pattern found everywhere: a hidden process unfolding over time, glimpsed only through noisy evidence. The predict-then-update cycle is the core of nearly all tracking systems.
