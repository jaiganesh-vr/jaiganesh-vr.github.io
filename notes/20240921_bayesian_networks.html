Bayesian Networks

Artificial Intelligence Probability

Sep 21, 2024

The full joint distribution answers any probabilistic question but grows exponentially with the number of variables. Bayesian networks represent the same distribution compactly by making conditional independence explicit in a graph.

The Structure

A Bayesian network is a directed acyclic graph:

  • Each node is a random variable.
  • An arrow from X to Y means X directly influences Y.
  • Each node has a conditional probability table, P(node | parents).

The Classic Example

A house has a burglar alarm that can be set off by a burglary or an earthquake. Two neighbours, John and Mary, may call when they hear it. The network has arrows Burglary → Alarm, Earthquake → Alarm, Alarm → JohnCalls and Alarm → MaryCalls.

John and Mary do not influence each other directly. Once we know whether the alarm rang, their calls are independent.

The Joint Distribution

The network defines the full joint distribution as a product of local tables:

P(x₁, …, xₙ) = Π P(xᵢ | parents(Xᵢ))

For the alarm network, that means 10 numbers instead of the 31 needed for a full table over five Boolean variables. In general, if each of n Boolean variables has at most k parents, the network needs about n · 2ᵏ numbers instead of 2ⁿ.

A Bayesian network turns an exponential table into a collection of small local ones.

Reading Independence

Each node is conditionally independent of its non-descendants, given its parents. More generally, d-separation tells us whether two variables are independent given some evidence, by examining the paths between them:

  • Chain, A → B → C: observing B blocks the path.
  • Common cause, A ← B → C: observing B blocks the path.
  • Common effect, A → B ← C: the path is blocked unless B, or one of its descendants, is observed.

The last case explains "explaining away". Burglary and earthquake are independent, but if the alarm rang and we learn there was an earthquake, burglary becomes less likely.

Inference

Inference computes the posterior distribution of query variables given evidence. Exact methods include enumeration and variable elimination, which avoids repeated work by caching intermediate factors.

For networks shaped like trees, called polytrees, exact inference is linear in size. In general it is NP-hard, which is why approximate methods based on sampling are important.

Building Networks

Networks can be built from expert knowledge, by ordering variables so that causes come before effects, or learned from data. Causal ordering usually gives the simplest network.

Closing Thought

Bayesian networks connect probability with structure. They make it possible to reason correctly about uncertainty in problems with many variables, as long as most of them influence only a few others.
