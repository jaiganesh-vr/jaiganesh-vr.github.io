Inference in First-Order Logic

Artificial Intelligence Logic

Apr 08, 2023

Reasoning in first-order logic means handling variables and quantifiers. The central tool that makes it practical is unification, which finds substitutions that make different expressions match.

Propositionalisation

One approach is to replace universally quantified sentences with all of their ground instances, then use propositional inference. It works in principle, but with function symbols there are infinitely many ground terms, and even without them the number of instances explodes.

Unification

Unification finds a substitution θ that makes two sentences identical:

  • Knows(John, x) and Knows(John, Jane) unify with {x / Jane}.
  • Knows(John, x) and Knows(y, Bill) unify with {x / Bill, y / John}.
  • Knows(John, x) and Knows(x, Elizabeth) fail, because x cannot be both John and Elizabeth. Renaming variables apart fixes this.

The most general unifier makes the fewest commitments, keeping later inference as flexible as possible.

Generalised Modus Ponens

With unification, modus ponens lifts to first-order logic. From King(x) ∧ Greedy(x) ⇒ Evil(x), King(John) and Greedy(John), we infer Evil(John) using the substitution {x / John}.

Unification lets one rule apply to every object it matches, instead of one rule per object.

Forward and Backward Chaining

For first-order definite clauses, both chaining strategies carry over.

  • Forward chaining adds every new fact derivable from the current facts until nothing new appears. It is the basis of production systems and deductive databases.
  • Backward chaining works from a goal, finding rules whose conclusion unifies with it and recursively proving their premises. It is the basis of logic programming.

Logic Programming

Prolog is the best-known logic programming language. A program is a set of definite clauses, and running it means posing a query that is answered by depth-first backward chaining. 

parent(tom, bob).
parent(bob, ann).
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).

?- grandparent(tom, Who).
Who = ann.

Prolog trades completeness for efficiency: its depth-first strategy can loop on some programs that have answers.

Resolution

Resolution extends to first-order logic using unification and clauses in conjunctive normal form, with existential variables replaced by Skolem functions. It is refutation-complete: if a sentence is entailed, a proof will be found.

But first-order entailment is semi-decidable. If a sentence is not entailed, the procedure may run forever, and no algorithm can always detect that.

Closing Thought

First-order inference is powerful but must be managed carefully. Most practical systems restrict the language, as Prolog and databases do, to keep reasoning efficient.
