Heuristic Functions

Artificial Intelligence Search

Nov 23, 2019

Uninformed search explores blindly. Informed search uses a heuristic function, h(n), which estimates the cost of the cheapest path from a state n to a goal. A good heuristic can turn an impossible search into a fast one.

Example: The 8-Puzzle

Two classic heuristics for the sliding tile puzzle:

  • h₁, misplaced tiles: count the tiles not in their goal position.
  • h₂, Manhattan distance: sum, over all tiles, of the horizontal and vertical distance to the goal position.

Both are cheap to compute and both never overestimate the true number of moves, since each misplaced tile needs at least one move, and in fact at least its Manhattan distance.

Admissibility

A heuristic is admissible if it never overestimates the true cost to reach the goal. Admissible heuristics are optimistic. This property is what guarantees that A* tree search returns an optimal solution.

Consistency

A heuristic is consistent if, for every node n and successor n' reached with step cost c:

h(n) ≤ c + h(n')

This is a form of the triangle inequality. Every consistent heuristic is admissible, and consistency guarantees A* graph search is optimal without reopening nodes.

Dominance

If h₂(n) ≥ h₁(n) for every n, and both are admissible, h₂ dominates h₁. A dominating heuristic never expands more nodes. Manhattan distance dominates misplaced tiles, and in practice expands far fewer nodes on deeper puzzles.

Prefer the larger heuristic, as long as it stays admissible and cheap to compute.

Inventing Heuristics by Relaxation

A relaxed problem has fewer restrictions on actions. The cost of an optimal solution to a relaxed problem is an admissible heuristic for the original.

  • If a tile could move anywhere, we get misplaced tiles.
  • If a tile could move to any adjacent square, even occupied, we get Manhattan distance.

Other techniques include pattern databases, which precompute exact costs for subproblems, and learning heuristics from solved examples.

Effective Branching Factor

Heuristic quality can be measured by the effective branching factor b*: the branching factor a uniform tree would need to contain the number of nodes actually expanded. Good heuristics push b* close to 1.

Closing Thought

A heuristic is knowledge compressed into a number. The better it approximates the true remaining cost, the less of the space search has to explore.
