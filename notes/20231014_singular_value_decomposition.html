The Singular Value Decomposition

Mathematics Linear Algebra

Oct 14, 2023

Eigenvectors simplify a matrix, but only some square matrices have enough of them, and they are rarely perpendicular. The singular value decomposition removes these limits. Every matrix, of any shape, acts simply when given the right pair of orthonormal bases.

The Claim

For any m × n matrix A with rank r, there are orthonormal bases of the input and output spaces such that:

A vᵢ = σᵢ uᵢ, for i = 1, …, r, with σ₁ ≥ σ₂ ≥ … ≥ σᵣ > 0

The remaining vs are sent to zero. In matrix form, with the vectors as columns:

A = U Σ Vᵀ

Eigenvectors stay on their own line. Singular vectors move to a different direction, but perpendicular inputs stay perpendicular.

Why It Exists

The trick is to find a square, symmetric matrix to work with. AᵀA is symmetric and positive semi-definite, so it has orthonormal eigenvectors vᵢ with eigenvalues λᵢ ≥ 0. Take these vs as inputs, and look at the outputs:

(A vᵢ)ᵀ(A vⱼ) = vᵢᵀ AᵀA vⱼ = λⱼ vᵢᵀvⱼ

This is zero if i ≠ j, so the outputs Avᵢ are orthogonal as well. The same calculation at i = j shows that ‖Avᵢ‖² = λᵢ. So normalise by defining:

σᵢ = √λᵢ and uᵢ = A vᵢ / σᵢ

That is the whole proof of existence, and it is also a recipe.

A Worked Example

Take A = [[3, 0], [4, 5]]. Then:

AᵀA = [[25, 20], [20, 25]]

Its eigenvalues are 45 and 5, with eigenvectors (1, 1)/√2 and (1, −1)/√2. Therefore σ₁ = √45 and σ₂ = √5. Applying A to the eigenvectors gives the left singular vectors:

u₁ = (1, 3)/√10 and u₂ = (3, −1)/√10

As a check, the product of the singular values is √45 · √5 = 15, which matches |det A| = 15. 

import numpy as np

A = np.array([[3.0, 0.0], [4.0, 5.0]])

# The recipe, step by step
eigenvalues, V = np.linalg.eigh(A.T @ A)
order = np.argsort(eigenvalues)[::-1]
eigenvalues, V = eigenvalues[order], V[:, order]
sigma = np.sqrt(eigenvalues)
U = A @ V / sigma

print(sigma.round(4))                              # [6.7082 2.2361]
print(np.allclose(U @ np.diag(sigma) @ V.T, A))    # True
print(np.linalg.svd(A, compute_uv=False).round(4)) # the same values

Forming AᵀA is good for understanding but poor for accuracy, because it squares the condition number. Library routines avoid it.

The Four Subspaces

The SVD gives orthonormal bases for all four fundamental subspaces at once:

  • Row space: v₁, …, vᵣ.
  • Null space: vᵣ₊₁, …, vₙ.
  • Column space: u₁, …, uᵣ.
  • Left null space: uᵣ₊₁, …, uₘ.

A matrix takes its row space to its column space, one basis vector at a time, with each stretched by σᵢ. It sends the null space to zero.

The Geometry

Read from right to left, A = UΣVᵀ is a rotation, a stretching along the axes, and a second rotation (allowing for reflections). So a matrix sends the unit sphere to an ellipsoid. The σs are the lengths of its semi-axes, and the us give their directions. The largest singular value σ₁ is the most that A can stretch any vector, which makes it the matrix's norm.

The Pseudoinverse

Each σᵢ can be undone, as long as it is not zero. Inverting these while leaving the zeros in place gives:

A⁺ = V Σ⁺ Uᵀ

This works for any matrix. A⁺b gives the least squares solution with the smallest norm, and it handles rank-deficient problems where the normal equations fail. When some σᵢ are very small, it is common to treat them as zero, since dividing by them would blow up noise.

The ratio σ₁ / σᵣ is the condition number, which measures how much a linear system can amplify error.

Closing Thought

Eigenvalues describe what a matrix does to a space when input and output are treated as the same. By allowing two different bases, the SVD applies to everything, and it is the most complete single description of a matrix that we have.
