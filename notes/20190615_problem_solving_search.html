Problem Solving as Search

Artificial Intelligence Search

Jun 15, 2019

Many AI problems share a structure: there is a starting situation, a goal, and a set of actions that change the situation. Finding a sequence of actions that reaches the goal is a search problem.

Formulating a Problem

A search problem is defined by:

  • Initial state: where the agent starts.
  • Actions: what can be done in each state.
  • Transition model: the state that results from each action.
  • Goal test: whether a state satisfies the goal.
  • Path cost: the cost of a sequence of actions, usually a sum of step costs.

A solution is a sequence of actions from the initial state to a goal state. An optimal solution has the lowest path cost.

Abstraction

Formulation is where most of the work happens. A route-finding problem does not model weather, traffic lights or the radio. Good abstraction removes detail that does not affect the solution, while keeping every abstract action executable in the real world.

A good formulation is as simple as possible, but no simpler.

Examples

  • The 8-puzzle: states are tile arrangements, actions slide the blank tile.
  • Route finding: states are cities, actions are roads, costs are distances.
  • The 8-queens problem: place queens so that none attack each other.

The 8-puzzle has 9!/2 = 181,440 reachable states. The 15-puzzle has around 10 trillion, which shows how quickly state spaces grow.

Search Trees and Graphs

Search algorithms explore the state space by building a search tree. The root is the initial state; expanding a node generates its children. The frontier is the set of nodes generated but not yet expanded.

Because many paths can lead to the same state, a tree can repeat states endlessly. Graph search keeps a set of already-explored states and skips them, which avoids redundant work.

Measuring Search Algorithms

  • Completeness: does it always find a solution if one exists?
  • Optimality: does it find the cheapest solution?
  • Time complexity: how many nodes does it generate?
  • Space complexity: how many nodes must it keep in memory?

Complexity is expressed in terms of the branching factor b, the depth of the shallowest goal d, and the maximum depth m.

Closing Thought

Search is the first general method AI offers: describe the problem precisely, and a generic algorithm can solve it. The challenge is doing so without exploring an astronomically large space.
