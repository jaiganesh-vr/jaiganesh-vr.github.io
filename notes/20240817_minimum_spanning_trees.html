Minimum Spanning Trees

Algorithms Graphs

Aug 17, 2024

Suppose you need to connect a set of towns with cables, and each possible link has a cost. The cheapest network that connects every town is a minimum spanning tree: a subset of edges that connects all vertices with no cycles and minimum total weight.

The Generic Approach

Both classic MST algorithms grow a set of edges A that is always a subset of some minimum spanning tree. At each step they add a safe edge, one that keeps this true.

The Cut Property

A cut divides the vertices into two groups. An edge crosses the cut if its endpoints are in different groups.

The lightest edge crossing any cut that respects A is safe to add.

If an MST did not contain that edge, swapping it in for a heavier edge crossing the same cut would give a tree that is no heavier. This one lemma proves both algorithms correct.

Kruskal's Algorithm

Kruskal's algorithm considers edges in increasing order of weight and adds each edge that does not create a cycle. 

def kruskal(n, edges):
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]   # path halving
            x = parent[x]
        return x

    tree = []
    for w, u, v in sorted(edges):
        ru, rv = find(u), find(v)
        if ru != rv:            # different components: no cycle
            parent[ru] = rv
            tree.append((u, v, w))
    return tree

A disjoint-set structure tracks which vertices are already connected. Sorting dominates, so the running time is O(E lg V).

Prim's Algorithm

Prim's algorithm grows a single tree from a starting vertex. At each step it adds the lightest edge connecting the tree to a vertex outside it, using a priority queue keyed by each outside vertex's cheapest connection.

With a binary heap, Prim's algorithm runs in O(E lg V). With a Fibonacci heap, it improves to O(E + V lg V), which helps on dense graphs.

Choosing Between Them

  • Kruskal: simple, works well on sparse graphs, and naturally handles disconnected graphs, producing a spanning forest.
  • Prim: resembles Dijkstra's algorithm, and is often faster on dense graphs.

Both are greedy algorithms whose greedy choice is justified by the cut property.

Applications

Network design, cluster analysis (removing the heaviest MST edges splits data into clusters), and approximation algorithms for problems like the travelling salesperson all build on minimum spanning trees.

Closing Thought

Minimum spanning trees are a rare case where greedy choices are provably optimal. One clean lemma, the cut property, turns two simple procedures into exact algorithms.
