Naive Bayes

Artificial Intelligence Probability

Jun 29, 2024

Naive Bayes is one of the simplest probabilistic classifiers and still a strong baseline for text classification. It applies Bayes' rule with one bold simplifying assumption.

The Model

We want the most probable class given a set of features, such as whether an email is spam given the words in it. By Bayes' rule:

P(class | features) ∝ P(features | class) · P(class)

Estimating P(features | class) for every combination of words is impossible. Naive Bayes assumes all features are conditionally independent given the class:

P(class | f₁, …, fₙ) ∝ P(class) · Π P(fᵢ | class)

The assumption is naive, because words in an email are clearly not independent. Yet the classifier works well in practice, because it only needs to rank classes correctly, not estimate exact probabilities.

Training

Training is just counting:

  • P(class): the fraction of training examples in each class.
  • P(word | class): how often each word appears in examples of that class.

This makes naive Bayes extremely fast to train and easy to update with new data.

Two Practical Details

  • Smoothing: a word never seen in spam during training would get probability zero, wiping out the whole product. Laplace smoothing adds one to every count so no probability is ever zero.
  • Log probabilities: multiplying hundreds of small probabilities underflows. Summing their logarithms gives the same ranking safely.
import math
from collections import Counter

def train(docs, labels):
    classes = set(labels)
    prior = {c: labels.count(c) / len(labels) for c in classes}
    counts = {c: Counter() for c in classes}
    for words, c in zip(docs, labels):
        counts[c].update(words)
    vocab = {w for words in docs for w in words}
    return prior, counts, vocab

def classify(words, prior, counts, vocab):
    def score(c):
        total = sum(counts[c].values()) + len(vocab)
        return math.log(prior[c]) + sum(
            math.log((counts[c][w] + 1) / total) for w in words)
    return max(prior, key=score)

Count, smooth, take logs, add. That is the whole classifier.

Strengths and Weaknesses

  • Strengths: fast, needs little data, handles many features, and is easy to interpret.
  • Weaknesses: probability estimates are poorly calibrated, often too close to 0 or 1, and strongly correlated features get counted several times.

Where It Is Used

Spam filtering, document categorisation, sentiment analysis and simple medical diagnosis systems have all used naive Bayes. It remains a sensible first model to try before reaching for something heavier.

Closing Thought

Naive Bayes shows that a model can be wrong in its assumptions and still useful in its predictions. The next step, Bayesian networks, keeps only the independence assumptions that are actually justified.
