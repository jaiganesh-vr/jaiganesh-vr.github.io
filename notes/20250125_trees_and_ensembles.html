Decision Trees and Ensembles

Machine Learning Ensemble Methods

Jan 25, 2025

Decision trees are easy to understand and take little preparation of data, but one tree on its own is rarely very accurate. Combining many of them produces models that are still among the strongest options for tabular data.

Growing a Tree

A tree divides the feature space into boxes through a series of yes-or-no questions, such as whether age is above 40. Prediction is the majority class, or the average target, in the box a point lands in. Finding the optimal tree is NP-hard, so trees are grown greedily. At each node, choose the split that most reduces impurity:

  • Gini impurity: Σ pₖ (1 − pₖ), the chance of misclassifying a random point if labelled at random according to the node's class proportions.
  • Entropy: − Σ pₖ log pₖ, the basis of information gain.
  • Variance: used for regression.
import numpy as np

def gini(y):
    p = np.bincount(y) / len(y)
    return 1 - (p**2).sum()

def best_split(x, y):
    """Best threshold on one feature, by weighted Gini."""
    best_score, best_t = gini(y), None
    for t in np.unique(x)[:-1]:
        left, right = y[x <= t], y[x > t]
        score = (len(left) * gini(left) + len(right) * gini(right)) / len(y)
        if score < best_score:
            best_score, best_t = score, t
    return best_t, best_score

x = np.array([1, 2, 3, 4, 5, 6])
y = np.array([0, 0, 0, 1, 1, 1])
print(best_split(x, y))  # splits at 3, with impurity 0

Why Trees Are Unstable

A deep tree can memorise its training set, and early splits constrain all later ones, so a small change in the data can produce a very different tree. Trees have low bias and high variance. Pruning or limiting depth helps a bit, but averaging does far better.

Bagging

Bootstrap aggregating trains each tree on a bootstrap sample and averages their predictions. If B trees each have variance σ² and pairwise correlation ρ, the variance of the average is:

ρσ² + (1 − ρ) σ² / B

More trees reduce the second term to zero, but not the first. Beyond a point, what limits the ensemble is how correlated its members are. On the plus side, about 37% of points are left out of each bootstrap sample, giving a free out-of-bag validation estimate.

Random Forests

Random forests reduce the correlation by considering only a random subset of the features at each split, often √d for classification. Otherwise, one strong feature would sit at the top of nearly every tree. Adding trees does not cause overfitting, and random forests work well with very little tuning.

Bagging makes unstable models stable. Feature subsampling makes the average worth more by keeping the trees different.

Boosting

Boosting builds trees in sequence, each correcting the errors made so far. Gradient boosting frames this as gradient descent in function space. At each round, fit a small tree to the negative gradient of the loss, which for squared error is just the residual:

Fₘ(x) = Fₘ₋₁(x) + η · hₘ(x)

Bagging starts with low-bias, high-variance trees and reduces variance. Boosting starts with shallow high-bias trees and reduces bias. Unlike forests, boosting can overfit if it runs too long, so the number of rounds, the learning rate η and the tree depth all need tuning, often with early stopping on a validation set.

Which to Use

  • Random forest: a robust default that needs little tuning and is hard to break.
  • Gradient boosting: often the most accurate on tabular data, using libraries such as XGBoost, LightGBM or CatBoost, given some tuning.
  • Single tree: when a model must be read and explained by a person.

A Note on Interpretation

Trees handle mixed feature types and do not care about feature scale. But impurity-based feature importance is biased toward features with many distinct values, and it splits credit across correlated features. Permutation importance or SHAP values are often preferable for explaining an ensemble.

Closing Thought

Ensembles show the bias-variance tradeoff in practice. Instead of searching for one good model, they combine many imperfect ones and cancel out the errors that do not agree.
