Q-Learning

Artificial Intelligence Reinforcement Learning

Jun 06, 2026

Value iteration needs a model: the transition probabilities and rewards of every action. Often no such model exists. A robot does not know in advance how its wheels slip; a game-playing agent does not know its opponent. Reinforcement learning learns good behavior directly from experience, and Q-learning is its classic algorithm.

Action Values

Instead of the utility of a state, Q-learning learns Q(s, a), the expected total discounted reward of taking action a in state s and acting optimally afterwards.

The advantage is that choosing actions no longer needs a model. The best action in s is simply the one with the highest Q(s, a).

The Update

After taking action a in state s, receiving reward r and arriving in s', the agent updates:

Q(s, a) ← Q(s, a) + α [ r + γ maxₐ' Q(s', a') − Q(s, a) ]

  • r + γ max Q(s', a') is the target: what the experience suggests the value should be.
  • The bracket is the temporal-difference error, the gap between target and current estimate.
  • α is the learning rate, controlling how far each update moves.
import random

def q_learning_step(Q, s, actions, env, alpha=0.1, gamma=0.99, epsilon=0.1):
    if random.random() < epsilon:
        a = random.choice(actions)                           # explore
    else:
        a = max(actions, key=lambda act: Q.get((s, act), 0.0))  # exploit
    s2, r, done = env.step(a)
    best_next = 0.0 if done else max(Q.get((s2, a2), 0.0) for a2 in actions)
    old = Q.get((s, a), 0.0)
    Q[(s, a)] = old + alpha * (r + gamma * best_next - old)
    return s2, done

Q-learning nudges each estimate toward the reward it saw plus the best value it expects next.

Exploration

An agent that always takes the action with the highest current Q may never discover better options. The simplest fix is ε-greedy: with small probability ε, take a random action. Decreasing ε over time shifts from exploring to exploiting.

Off-Policy Learning

Q-learning learns the value of the optimal policy, even while following an exploratory one, because its target uses the max over next actions rather than the action actually taken. This is called off-policy learning. SARSA, a close relative, uses the action actually taken, and so learns the value of the policy being followed.

Given enough exploration and a suitably decreasing learning rate, tabular Q-learning converges to the optimal action values.

The Scaling Problem

A table with one entry per state-action pair works for small problems. For backgammon, chess or anything with images as input, the table is impossibly large, and the agent must generalise from states it has seen to states it has not.

Closing Thought

Q-learning is learning by doing in its purest form: no model, just experience and a simple update rule. Making it work at scale requires function approximation, the subject of the next note.
