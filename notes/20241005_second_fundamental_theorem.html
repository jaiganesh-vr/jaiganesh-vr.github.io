The Second Fundamental Theorem of Calculus

Mathematics Calculus

Oct 05, 2024

The first fundamental theorem computes an integral from an antiderivative. But does an antiderivative always exist? The second theorem answers yes for every continuous function, and it does so by building one.

The Statement

If f is continuous, define a new function by letting the upper limit vary:

G(x) = ∫ₐˣ f(t) dt

Then G is differentiable, and:

G′(x) = f(x)

Accumulate f up to x, then ask how fast that total is growing. The rate is f(x) itself.

Why It Is True

Think of G(x) as the area under f from a to x. Moving from x to x + h adds a thin strip with width h and height about f(x):

G(x + h) − G(x) = ∫ₓˣ⁺ʰ f(t) dt ≈ f(x) · h

Dividing by h and letting it go to zero gives the result. The step that needs care is the approximation. It holds because f is continuous, so on a short interval f stays close to f(x).

Note that the variable of integration, t, is a dummy variable, while x is a limit of integration. Using the same letter for both is a common source of confusion.

The Chain Rule Version

With a variable upper limit, the chain rule adds one factor:

d/dx ∫ₐ^g(x) f(t) dt = f(g(x)) · g′(x)

For example:

d/dx ∫₀^(x²) cos t dt = cos(x²) · 2x

It can be checked in this case, since the integral is sin(x²), whose derivative matches. If both limits vary, take the difference of the two terms:

d/dx ∫_h(x)^g(x) f(t) dt = f(g(x)) g′(x) − f(h(x)) h′(x) 

import numpy as np

def G(x, n=200_000):
    """Integral of cos t from 0 to x squared, by the midpoint rule."""
    dt = x**2 / n
    t = dt * (np.arange(n) + 0.5)
    return (np.cos(t) * dt).sum()

x, h = 1.3, 1e-4
numeric = (G(x + h) - G(x - h)) / (2 * h)
exact = np.cos(x**2) * 2 * x
print(round(numeric, 5), round(exact, 5))   # these agree

How It Implies the First Theorem

Let F be any antiderivative of f, and G be as above. Since G′ = f = F′, the two differ by a constant:

F(x) = G(x) + C

Evaluating at b and a gives F(b) − F(a) = G(b) − G(a) = ∫ₐᵇ f(t) dt, since G(a) = 0. So the two theorems are close partners, with this one providing a guaranteed antiderivative.

Integrals That Define Functions

Every continuous function has an antiderivative, but the antiderivative is not always made of familiar pieces. The theorem lets us define these functions as integrals:

  • The logarithm: ln x = ∫₁ˣ dt / t. This could serve as its definition, and gives (ln x)′ = 1/x right away.
  • The error function: erf(x) = (2/√π) ∫₀ˣ e^(−t²) dt.
  • The normal CDF: Φ(x) = (1/√(2π)) ∫₋∞ˣ e^(−t²/2) dt, the area to the left of x under the standard bell curve.
  • Fresnel integrals: C(x) = ∫₀ˣ cos(t²) dt, first studied in optics.

These are as legitimate as sin x or eˣ. We know their derivatives exactly, and they can be computed as accurately as necessary. They just need a name, which is how some functions get into libraries. Note that the normal CDF's derivative is the density, so in probability, this theorem connects the CDF and the PDF.

Properties From the Derivative

Since G′ = f is known exactly, it is easy to analyse these functions without any formula. The sign of f says where G rises and falls, and f′ says where G curves. For example, ln x has derivative 1/x > 0 on x > 0, so it is always rising, and its second derivative is −1/x² < 0, so it is concave.

Differential equations follow the same approach. y′ = f(x) with y(a) = y₀ has the solution y = y₀ + ∫ₐˣ f(t) dt. This is why solving differential equations is often called integrating them.

Closing Thought

The second theorem guarantees that every continuous function has an antiderivative, whether or not it can be written down. Finding an antiderivative that can be written down is a separate challenge, and it takes some technique.
