Monte Carlo Inference

Machine Learning Approximate Inference

Oct 11, 2025

Bayesian inference is mostly about integrals: posterior means, predictive distributions, evidence. For nearly all interesting models these have no closed form, and grids become impossible beyond a few dimensions. Monte Carlo methods swap the integral for an average over random samples.

The Basic Idea

Any expectation can be approximated using samples from the distribution:

E[f(x)] ≈ (1/S) Σₛ f(xₛ), where xₛ ~ p(x)

The estimate is unbiased, and by the central limit theorem its standard error is:

σ_f / √S

The remarkable feature is that this rate does not depend on the dimension of x. A grid needs a number of points that is exponential in dimension. Monte Carlo needs a number of samples set by the variance of f and the accuracy required. The downside is slow convergence, since one more decimal place costs a hundred times as many samples.

Monte Carlo is rarely very accurate, but it often works where nothing else can.

Getting Samples

All of this requires a way to draw samples, which is the hard part.

  • Inverse CDF: if U is uniform, then F⁻¹(U) has distribution F. This gives exact samples whenever the inverse CDF is available, such as with the exponential.
  • Rejection sampling: choose a proposal q and constant M with M·q(x) ≥ p̃(x) everywhere. Sample x from q and keep it with probability p̃(x) / (M q(x)).

Rejection sampling needs only an unnormalised density, but in high dimensions its acceptance rate tends to collapse exponentially, because M must grow to cover the target along every dimension.

Importance Sampling

Importance sampling keeps every sample and corrects with a weight:

E_p[f(x)] = E_q[ f(x) · p(x) / q(x) ]

With an unnormalised posterior p̃ we normalise the weights, which adds a small bias that shrinks as S grows:

E_p[f] ≈ Σₛ wₛ f(xₛ) / Σₛ wₛ, where wₛ = p̃(xₛ) / q(xₛ)

Here it is estimating the mean of the Beta(9, 5) posterior for our coin, whose true value is 9 / 14 ≈ 0.643, without using the normalising constant: 

import numpy as np

rng = np.random.default_rng(0)

def target(theta):                          # unnormalised posterior
    return theta**8 * (1 - theta)**4

theta = rng.uniform(0, 1, 100_000)          # proposal: uniform
w = target(theta)                           # q(x) = 1 on [0, 1]

print((w * theta).sum() / w.sum())          # about 0.643
print(w.sum()**2 / (w**2).sum())            # effective sample size

Diagnosing Weights

If q poorly matches p, a few samples receive nearly all of the weight, and the estimate effectively rests on those. A common diagnostic is the effective sample size:

ESS = (Σ wₛ)² / Σ wₛ²

A sharp target in high dimensions has almost no overlap with a simple proposal, so the ESS falls to near one. An estimate can look stable and still be badly wrong if the proposal has missed a region of the target. To be safe, q should have heavier tails than p.

Reducing Variance

  • Control variates: subtract a correlated quantity with known expectation.
  • Antithetic sampling: use pairs of negatively correlated samples, so that their errors partly cancel.
  • Rao-Blackwellisation: integrate out what can be done analytically, and sample only the rest.

Where It Fails, and What Comes Next

Independent sampling struggles in high dimensions, since a fixed proposal cannot find where a complicated posterior puts its mass. That mass tends to be concentrated in a tiny part of the space. The better approach is to let samples explore locally, moving toward regions of high probability and spending time there.

Closing Thought

Monte Carlo reduces integration to sampling, for any dimension. When independent samples become too hard to get, we accept dependent ones instead, which is the idea behind Markov chain Monte Carlo.
