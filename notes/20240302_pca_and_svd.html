Principal Component Analysis and the SVD

Machine Learning Dimensionality Reduction

Mar 02, 2024

High-dimensional data often has few real degrees of freedom. Principal component analysis finds the directions along which the data actually varies, and it is computed reliably with one of the most useful tools in numerical linear algebra.

Two Views, One Answer

Assume the data has been centred. PCA looks for an orthonormal set of k directions, and can be motivated in two ways:

  • Maximum variance: choose directions along which the projected data has the greatest spread.
  • Minimum reconstruction error: choose the k-dimensional subspace that loses the least when data is projected on it and mapped back.

These agree because of Pythagoras. For each point, the squared length is fixed and equals its projected part plus its residual part, so maximising one minimises the other.

Deriving the First Component

The variance of data projected onto a unit vector w is:

Var = wᵀ S w, with S = (1/(n − 1)) XᵀX

Maximising subject to ‖w‖ = 1, using a Lagrange multiplier, gives:

S w = λ w

So the best direction is an eigenvector of the covariance matrix, and the variance captured equals its eigenvalue. The first principal component is the eigenvector with the largest eigenvalue, and the next ones follow in order, each orthogonal to those before.

Computing It With the SVD

Forming S can lose precision, since squaring the data squares its condition number. The better route factors the centred data directly:

X = U Σ Vᵀ

Substituting this into S shows that everything PCA needs is here:

  • Components: the columns of V.
  • Variance along each: σᵢ² / (n − 1).
  • Projected coordinates: U Σ, or equivalently X V.

The rank-k reconstruction, U_k Σ_k V_kᵀ, is the best rank-k approximation to X in squared error, by the Eckart-Young theorem. This is why the two views of PCA agree with the SVD. 

import numpy as np

def pca(X, k):
    mean = X.mean(axis=0)
    U, s, Vt = np.linalg.svd(X - mean, full_matrices=False)
    explained = s**2 / (s**2).sum()
    return Vt[:k], (U * s)[:, :k], mean, explained[:k]

rng = np.random.default_rng(0)
latent = rng.normal(size=(500, 2))
X = latent @ rng.normal(size=(2, 10)) + rng.normal(0, 0.05, (500, 10))

components, Z, mean, explained = pca(X, 3)
print(explained.round(4))  # two directions hold nearly all the variance

How Many Components

  • Variance explained: keep enough to reach, say, 95% of the total variance.
  • Scree plot: plot the eigenvalues in order and look for an elbow.
  • Downstream performance: treat k as a hyperparameter and pick it by validation.

Where PCA Misleads

  • Scale: PCA follows variance, so a feature in millimetres dominates the same feature in metres. Standardise features when units differ.
  • Variance is not relevance: the direction of greatest variance need not be the one that matters for a label. It could just be noise or a batch effect.
  • Linearity: data on a curved surface needs more components than its true dimension. Kernel PCA, t-SNE, UMAP and autoencoders are alternatives.
  • Outliers: because the variance is squared, a few extreme points can tilt the components.
  • Leakage: fit the mean and components on training data only.

Probabilistic PCA

PCA can be derived as a latent variable model, x = Wz + μ + ε, with Gaussian z and isotropic Gaussian noise. The maximum likelihood W spans the same subspace as PCA. This connects it to factor analysis, provides a likelihood for model comparison, and allows EM to be used for missing data or very large matrices.

Closing Thought

PCA asks a simple question, which directions matter most, and linear algebra answers it exactly. Its reliance on dot products also sets up a useful trick: replace those dot products with something else, and linear methods become nonlinear.
