Convex Functions and Convex Optimization

Mathematics Optimization

Mar 29, 2025

Some optimisation problems are tractable and others are nearly impossible. The important dividing line turned out to be not linear versus nonlinear, but convex versus non-convex.

Convex Sets and Functions

A set is convex if the line segment between any two of its points stays inside it. A function is convex if the segment between any two points on its graph lies on or above the graph:

f(t x + (1 − t) y) ≤ t f(x) + (1 − t) f(y), for t in [0, 1]

Equivalent Tests

For differentiable functions, these are the same condition:

  • First order: f(y) ≥ f(x) + ∇f(x)ᵀ(y − x). The tangent always lies below the function.
  • Second order: the Hessian is positive semi-definite everywhere.

The first order condition has a striking consequence. If ∇f(x) = 0, the right side reduces to f(x), so f(y) ≥ f(x) for every y.

In a convex function, every local minimum is a global minimum, and a zero gradient is a certificate of optimality.

Recognising Convexity

Rather than checking from scratch, build complicated functions from simple ones, using rules that preserve convexity:

  • Basic examples: linear functions, norms, x², eˣ, and −log x for x > 0.
  • Nonnegative sums: adding convex functions, or multiplying by a positive constant.
  • Affine composition: f(Ax + b) is convex if f is convex.
  • Pointwise maximum: the maximum of several convex functions, as in the hinge loss.

These show that least squares, logistic regression, ridge, lasso and SVMs are all convex.

Strong Convexity and Convergence Rates

A function is μ-strongly convex if its curvature is at least μ everywhere. It then has a single unique minimum. If the gradient is also L-Lipschitz, gradient descent with a step size of 1/L has known rates:

  • Convex and smooth: error falls as O(1/k).
  • Strongly convex and smooth: error falls geometrically, as (1 − μ/L)ᵏ.

The ratio L/μ is the condition number. Adding an L2 penalty λ‖w‖² adds 2λ to all the Hessian's eigenvalues, so it makes a convex problem strongly convex and also better conditioned. 

import numpy as np

def gd(H, steps):
    """Gradient descent on 0.5 x'Hx with step size 1/L."""
    L = np.linalg.eigvalsh(H).max()
    x = np.ones(len(H))
    for _ in range(steps):
        x = x - (1 / L) * (H @ x)
    return 0.5 * x @ H @ x

well_conditioned = np.diag([1.0, 2.0])
badly_conditioned = np.diag([0.01, 2.0])

print(gd(well_conditioned, 50))     # effectively zero
print(gd(badly_conditioned, 50))    # far larger
print(gd(badly_conditioned + 0.5 * np.eye(2), 50))  # regularised: much better

Constraints

Convex optimisation also handles constraints well. Minimising a convex function over a convex set still has no spurious local minima. Projected gradient descent takes a step and maps the result back to the set. Other approaches include interior point methods, which handle inequality constraints using barrier functions.

Non-Convex Reality

The loss of a neural network is highly non-convex, with symmetries alone creating many equivalent minima. None of these guarantees apply, and yet gradient descent works very well in practice. Some partial explanations are:

  • Few bad minima: in very large networks, most local minima seem to have similar loss.
  • Saddles rather than minima: the main obstacles tend to be saddle points, which noise helps gradient methods escape.
  • Overparameterisation: with far more parameters than data, the landscape appears to become easier to navigate.

A full theory is still an open question. Convex analysis remains useful there, since it provides the concepts, such as smoothness and conditioning, used to reason about training.

Closing Thought

Convexity is what separates problems we can solve from problems we can only attempt. Recognising it means we can stop worrying about the optimiser and focus on the model. Constraints deserve further attention, as they have a beautiful theory of their own.
