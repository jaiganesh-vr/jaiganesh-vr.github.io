Dynamic Programming

Algorithms Design Techniques

Mar 04, 2023

Divide and conquer splits a problem into independent subproblems. When subproblems overlap, plain recursion solves the same ones over and over. Dynamic programming solves each subproblem once, stores the answer, and reuses it.

The Two Ingredients

  • Optimal substructure: an optimal solution contains optimal solutions to its subproblems.
  • Overlapping subproblems: a recursive solution revisits the same subproblems many times.

When both hold, dynamic programming typically turns exponential time into polynomial time.

Example: Rod Cutting

A rod of length n can be cut into pieces and sold, with price p[i] for a piece of length i. What cutting maximises revenue?

The best revenue for length n is the best choice of a first piece plus the best revenue for what remains:

r(n) = max over 1 ≤ i ≤ n of ( p[i] + r(n − i) )

A direct recursive implementation recomputes the same r values exponentially many times. Storing them fixes that.

Top-Down and Bottom-Up

  • Memoisation (top-down): write the natural recursion and cache each result the first time it is computed.
  • Tabulation (bottom-up): solve subproblems in order of size, filling a table so every needed value is ready when used.
def cut_rod(p, n):
    r = [0] * (n + 1)
    for j in range(1, n + 1):
        r[j] = max(p[i] + r[j - i] for i in range(1, j + 1))
    return r[n]

This runs in Θ(n²) instead of Θ(2ⁿ).

Dynamic programming is recursion with a memory.

Example: Longest Common Subsequence

Given two strings, find the longest sequence of characters appearing in both in the same order, not necessarily contiguously. For X and Y of lengths m and n, let c[i][j] be the LCS length of their first i and j characters:

  • If X[i] = Y[j], then c[i][j] = c[i − 1][j − 1] + 1.
  • Otherwise, c[i][j] = max(c[i − 1][j], c[i][j − 1]).

Filling the table takes Θ(mn). The same structure underlies diff tools and DNA sequence alignment.

Reconstructing Solutions

The table holds optimal values. To recover the actual solution, such as the cuts or the subsequence, store which choice achieved each optimum and trace back through the table.

A Recipe

  • Characterise the structure of an optimal solution.
  • Define the value of an optimal solution recursively.
  • Compute the values, usually bottom-up.
  • Reconstruct an optimal solution from the stored choices.

Closing Thought

The hard part of dynamic programming is finding the right subproblems. Once the recurrence is clear, the algorithm is usually just a loop that fills a table.
