Graph Traversal: BFS and DFS

Algorithms Graphs

Feb 24, 2024

Graphs model networks of every kind: roads, web links, dependencies, social connections. Most graph algorithms start by exploring the graph systematically, using one of two traversals.

Representing Graphs

  • Adjacency lists: for each vertex, a list of its neighbours. Space Θ(V + E), best for sparse graphs.
  • Adjacency matrix: a V × V table of edges. Space Θ(V²), constant-time edge lookup, best for dense graphs.

Most real graphs are sparse, so adjacency lists are the usual choice.

Breadth-First Search

BFS explores outward from a source in layers: first all vertices at distance 1, then distance 2, and so on, using a queue. 

from collections import deque

def bfs(graph, source):
    dist = {source: 0}
    queue = deque([source])
    while queue:
        u = queue.popleft()
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                queue.append(v)
    return dist

Each vertex is enqueued once and each edge examined once, so BFS runs in O(V + E). It computes shortest paths, in number of edges, from the source to every reachable vertex.

Depth-First Search

DFS goes as deep as possible before backtracking. It records two timestamps for each vertex: when it is discovered and when it is finished, after all its descendants have been explored. It also runs in O(V + E).

The timestamps reveal structure. Edges can be classified as tree, back, forward or cross edges, and a directed graph has a cycle exactly when DFS finds a back edge.

BFS answers how far. DFS answers how things are connected and ordered.

Topological Sort

In a directed acyclic graph, a topological sort orders vertices so that every edge points forward. It is how build systems order compilation and how task schedulers respect dependencies.

The algorithm is a single DFS: list vertices in decreasing order of finish time. A vertex finishes only after everything reachable from it, so it appears before all of them.

Strongly Connected Components

In a directed graph, a strongly connected component is a maximal set of vertices that can all reach one another. They can be found with two DFS passes: one on the graph to get finish times, and one on the graph with edges reversed, visiting vertices in decreasing finish time. Each tree in the second pass is one component.

Closing Thought

BFS and DFS are building blocks. Shortest paths, spanning trees, cycle detection, scheduling and connectivity all rest on these two ways of walking a graph.
