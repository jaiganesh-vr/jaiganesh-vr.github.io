Strassen's Algorithm for Matrix Multiplication

Algorithms Divide and Conquer

Oct 19, 2019

Multiplying two n × n matrices the straightforward way takes Θ(n³) operations: each of n² entries is a dot product of length n. For a long time this was assumed to be optimal. In 1969, Volker Strassen showed it is not.

Simple Divide and Conquer

Split each matrix into four n/2 × n/2 blocks: 

| C11 C12 |   | A11 A12 |   | B11 B12 |
| C21 C22 | = | A21 A22 | × | B21 B22 |

C11 = A11·B11 + A12·B21      C12 = A11·B12 + A12·B22
C21 = A21·B11 + A22·B21      C22 = A21·B12 + A22·B22

That needs eight multiplications of half-size matrices plus some additions, giving T(n) = 8T(n/2) + Θ(n²). By the master method, that is still Θ(n³). Dividing alone does not help.

Strassen's Insight

Strassen found a way to compute the four blocks of C using only seven multiplications, at the cost of more additions: 

M1 = (A11 + A22)(B11 + B22)
M2 = (A21 + A22) B11
M3 = A11 (B12 − B22)
M4 = A22 (B21 − B11)
M5 = (A11 + A12) B22
M6 = (A21 − A11)(B11 + B12)
M7 = (A12 − A22)(B21 + B22)

C11 = M1 + M4 − M5 + M7
C12 = M3 + M5
C21 = M2 + M4
C22 = M1 − M2 + M3 + M6

You can check each block by expanding the products; the unwanted terms cancel exactly.

The Payoff

The recurrence becomes:

T(n) = 7T(n/2) + Θ(n²)

Case 1 of the master method gives T(n) = Θ(n^(lg 7)) ≈ Θ(n^2.81).

Trading one multiplication for many additions pays off because additions are cheap and the saving repeats at every level.

Saving a single multiplication at the top would be trivial. The gain comes from applying the trick recursively at every level of the recursion.

In Practice

  • Constant factors are larger than the naive method, so Strassen only wins above a crossover size, typically a few hundred.
  • Implementations switch to ordinary multiplication for small blocks.
  • It is less numerically stable, which matters in floating-point scientific code.
  • It needs extra memory for intermediate matrices.

Beyond Strassen

Strassen's result started a long line of research. Later algorithms have pushed the theoretical exponent down to around 2.37, though their constants are so large they are not used in practice. Whether matrices can be multiplied in close to n² time remains an open question.

Closing Thought

Strassen's algorithm is a reminder that obvious bounds are not always real ones. A clever algebraic identity, applied recursively, broke an assumption that had seemed self-evident.
