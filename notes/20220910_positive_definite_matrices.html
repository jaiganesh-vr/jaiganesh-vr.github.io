Positive Definite Matrices and Quadratic Forms

Mathematics Linear Algebra

Sep 10, 2022

Positive definite matrices sit at the junction of optimisation, statistics and kernel methods. They are the matrix version of a positive number, and they guarantee that many calculations behave well.

Quadratic Forms

For a symmetric matrix A and a vector x, the quadratic form is a single number:

f(x) = xᵀ A x

With A = [[2, 1], [1, 2]], this gives f(x) = 2x₁² + 2x₁x₂ + 2x₂². The cross term is what makes the surface tilted relative to the axes.

The Definition

  • Positive definite: xᵀAx > 0 for every nonzero x.
  • Positive semi-definite: xᵀAx ≥ 0 for every x.
  • Indefinite: positive for some x and negative for others.

Geometrically, a positive definite form is a bowl with a unique lowest point at the origin. Its level sets are ellipses. A semi-definite one is a bowl with a flat valley, and an indefinite one is a saddle.

A positive definite matrix describes a bowl, and its eigenvectors give the axes of that bowl.

Equivalent Tests

For a symmetric matrix, these are the same statement:

  • All eigenvalues are positive.
  • It can be written as A = BᵀB for some B with independent columns.
  • All leading principal minors are positive.
  • It has a Cholesky factorisation.

To see the eigenvalue connection, write A = QΛQᵀ. Then with y = Qᵀx, the form becomes Σ λᵢ yᵢ², which is positive for all y exactly when every λᵢ is positive.

Our example has eigenvalues 3 and 1, so it is positive definite. Change the off-diagonal entries from 1 to 3 and the eigenvalues become 5 and −1, giving a saddle.

The Cholesky Factorisation

A positive definite matrix factors into a lower triangular matrix times its transpose:

A = L Lᵀ

This is about twice as fast as a general LU factorisation and it is numerically stable. It also doubles as the cheapest practical test for positive definiteness, since it fails if the matrix isn't. 

import numpy as np

def is_positive_definite(A):
    try:
        np.linalg.cholesky(A)
        return True
    except np.linalg.LinAlgError:
        return False

print(is_positive_definite(np.array([[2.0, 1.0], [1.0, 2.0]])))  # True
print(is_positive_definite(np.array([[2.0, 3.0], [3.0, 2.0]])))  # False

# Sampling from a Gaussian with covariance S: x = mu + L z
S = np.array([[2.0, 1.0], [1.0, 2.0]])
L = np.linalg.cholesky(S)
z = np.random.default_rng(0).normal(size=(100_000, 2))
print(np.cov((z @ L.T).T).round(2))

Where It Shows Up

  • Covariance matrices: always semi-definite, since the variance of any linear combination is xᵀΣx, which cannot be negative.
  • Second-order conditions: a positive definite Hessian at a stationary point means a local minimum. An indefinite one means a saddle.
  • Convexity: a twice-differentiable function is convex exactly when its Hessian is semi-definite everywhere.
  • Least squares: XᵀX is semi-definite, and adding λI in ridge regression makes it positive definite.
  • Kernels: Mercer's condition requires every Gram matrix to be semi-definite.
  • Gaussians: the exponent of a multivariate Gaussian is a quadratic form in the inverse covariance.

Numerical Trouble

Empirical covariance matrices are often only barely semi-definite, particularly with fewer examples than features, and rounding errors can then make Cholesky fail. The standard fix is to add a small jitter to the diagonal, A + εI. This shifts every eigenvalue up by ε and is common in Gaussian process code.

Closing Thought

Positive definiteness guarantees a single minimum, valid variances and stable computation. Now we turn to how to find directions of descent on surfaces that are not perfectly quadratic, which is the job of calculus.
