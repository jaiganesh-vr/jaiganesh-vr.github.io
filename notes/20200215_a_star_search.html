A* Search

Artificial Intelligence Search

Feb 15, 2020

A* is the best-known informed search algorithm and still the standard choice for pathfinding in games, robotics and route planning. It combines the cost already paid with an estimate of the cost remaining.

The Evaluation Function

A* expands the node with the lowest value of:

f(n) = g(n) + h(n)

  • g(n): the actual cost of the path from the start to n.
  • h(n): the heuristic estimate of the cost from n to the goal.

So f(n) estimates the total cost of the cheapest solution through n.

Comparison With Other Strategies

  • Uniform-cost search uses only g(n). It is optimal but explores in every direction.
  • Greedy best-first search uses only h(n). It heads straight for the goal but can be badly misled and is not optimal.
  • A* balances both: it moves toward the goal while accounting for cost so far.

The Algorithm

import heapq

def a_star(start, goal, neighbours, h):
    frontier = [(h(start), 0, start)]
    best_g = {start: 0}
    while frontier:
        f, g, node = heapq.heappop(frontier)
        if node == goal:
            return g
        for nxt, cost in neighbours(node):
            new_g = g + cost
            if new_g < best_g.get(nxt, float("inf")):
                best_g[nxt] = new_g
                heapq.heappush(frontier, (new_g + h(nxt), new_g, nxt))
    return None

Optimality

With an admissible heuristic, A* tree search is optimal. With a consistent heuristic, A* graph search is optimal, and the f values along any path never decrease, so the first time a goal is expanded its path is the cheapest.

A* is also optimally efficient: among algorithms that extend paths from the start using the same heuristic, no other is guaranteed to expand fewer nodes.

A* explores every node with f(n) below the optimal cost, and no others it can avoid.

The Catch: Memory

A* keeps every generated node in memory. On large problems it runs out of space long before it runs out of time. Memory-bounded variants address this:

  • IDA*: iterative deepening using an f-cost limit instead of a depth limit.
  • SMA*: uses all available memory and drops the worst nodes when full.

Closing Thought

A* shows how much a good estimate is worth. The algorithm is simple; its performance depends almost entirely on the quality of the heuristic it is given.
