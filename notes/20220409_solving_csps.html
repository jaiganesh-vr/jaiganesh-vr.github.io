Solving CSPs: Backtracking and Arc Consistency

Artificial Intelligence CSP

Apr 09, 2022

Constraint satisfaction problems are solved by combining search with inference. Search assigns values; inference uses the constraints to rule out values before they are tried.

Backtracking Search

Backtracking search is depth-first search that assigns one variable at a time and backs up as soon as a constraint is violated. 

def backtrack(assignment, csp):
    if len(assignment) == len(csp.variables):
        return assignment
    var = select_unassigned_variable(assignment, csp)
    for value in order_domain_values(var, assignment, csp):
        if csp.consistent(var, value, assignment):
            assignment[var] = value
            result = backtrack(assignment, csp)
            if result is not None:
                return result
            del assignment[var]
    return None

Because CSPs are commutative, the order of assignments does not change the result, so only one variable needs to be considered at each level.

Ordering Heuristics

  • Minimum remaining values (MRV): choose the variable with the fewest legal values left. It fails fast, pruning dead ends early.
  • Degree heuristic: break ties by choosing the variable involved in the most constraints with unassigned variables.
  • Least constraining value: try values that rule out the fewest choices for neighbouring variables.

Choose the most constrained variable, then the least constraining value.

Forward Checking

Whenever a variable is assigned, forward checking removes inconsistent values from the domains of its unassigned neighbours. If any domain becomes empty, the algorithm backtracks immediately.

Arc Consistency

An arc X → Y is consistent if, for every value of X, there is some value of Y that satisfies the constraint between them. The AC-3 algorithm enforces this across the whole problem:

  • Put every arc in a queue.
  • Remove an arc X → Y and delete any value of X with no supporting value in Y.
  • If X's domain changed, add all arcs Z → X back to the queue.
  • Repeat until the queue is empty.

AC-3 runs in O(c·d³) for c constraints and domain size d. Running it after each assignment, called maintaining arc consistency, detects failures much earlier than forward checking.

Smarter Backtracking

Chronological backtracking returns to the most recent decision, even if it had nothing to do with the failure. Conflict-directed backjumping jumps back to a variable actually responsible for the conflict.

Problem Structure

If the constraint graph is a tree, a CSP can be solved in time linear in the number of variables. Real problems can sometimes be reduced to trees by assigning a small set of variables first, called a cycle cutset.

Closing Thought

The power of CSP solvers comes from interleaving search with inference. Every value ruled out by propagation is a whole subtree that search never has to visit.
