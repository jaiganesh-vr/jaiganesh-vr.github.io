Intelligent Agents and Environments

Artificial Intelligence Agents

Mar 02, 2019

An agent is anything that perceives its environment through sensors and acts upon it through actuators. A thermostat, a chess program and a self-driving car all fit this definition. The framework is simple, but it gives a common language for very different AI systems.

Percepts, Actions and the Agent Function

At each moment an agent receives a percept. The full history of what it has perceived is its percept sequence. An agent's behavior is described by its agent function, a mapping from percept sequences to actions. The agent program is the concrete implementation of that function.

Performance Measures

Rationality is judged by a performance measure that evaluates the sequence of environment states the agent produces. Choosing it carefully matters.

Measure what you want in the environment, not how you think the agent should behave.

A cleaning robot rewarded for dirt picked up can learn to dump dirt and pick it up again. Rewarding a clean floor avoids that.

PEAS

Designing an agent starts by specifying its task environment:

  • Performance: what counts as success.
  • Environment: the world it operates in.
  • Actuators: how it can act.
  • Sensors: how it perceives.

Properties of Environments

  • Fully or partially observable: can the agent see everything relevant?
  • Deterministic or stochastic: is the next state fully determined by the action?
  • Episodic or sequential: do current decisions affect future ones?
  • Static or dynamic: does the world change while the agent thinks?
  • Discrete or continuous: are states and actions countable?
  • Single or multi-agent: are other agents acting too?

The hardest case, partially observable, stochastic, sequential, dynamic, continuous and multi-agent, describes everyday driving.

Kinds of Agent Programs

  • Simple reflex agents act on the current percept with condition-action rules.
  • Model-based agents keep an internal state describing parts of the world they cannot see.
  • Goal-based agents choose actions that lead toward a goal.
  • Utility-based agents choose actions that maximise expected happiness, trading off goals.
  • Learning agents improve all of the above from experience.

Closing Thought

The agent framework turns the vague question of building intelligence into specific design choices: what the agent sees, what it can do and how success is measured.
