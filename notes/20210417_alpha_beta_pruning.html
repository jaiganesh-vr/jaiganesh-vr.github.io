Alpha-Beta Pruning

Artificial Intelligence Games

Apr 17, 2021

Minimax examines every node in the game tree. Alpha-beta pruning returns exactly the same decision while ignoring branches that cannot possibly influence it. On good move orderings it can search roughly twice as deep in the same time.

The Key Insight

Suppose MAX has already found a move guaranteeing a value of 5. While examining another move, MAX sees that MIN can reply with something worth 3. MIN would never allow more than 3 there, so that whole move is worse than the 5 already secured. There is no need to look at MIN's other replies.

If a move is already known to be worse than an alternative, how much worse doesn't matter.

Alpha and Beta

The algorithm tracks two values during the search:

  • α (alpha): the best value found so far for MAX along the current path. MAX is guaranteed at least this.
  • β (beta): the best value found so far for MIN along the current path. MIN is guaranteed at most this.

Whenever α ≥ β at a node, the remaining children of that node are pruned. 

def alphabeta(state, alpha, beta, maximizing):
    if state.is_terminal():
        return state.utility()
    if maximizing:
        value = float("-inf")
        for child in state.children():
            value = max(value, alphabeta(child, alpha, beta, False))
            alpha = max(alpha, value)
            if alpha >= beta:
                break  # MIN will avoid this branch
        return value
    value = float("inf")
    for child in state.children():
        value = min(value, alphabeta(child, alpha, beta, True))
        beta = min(beta, value)
        if alpha >= beta:
            break  # MAX will avoid this branch
    return value

Move Ordering

Pruning effectiveness depends entirely on the order in which moves are examined. If the best moves are searched first, alpha-beta examines about O(b^(m/2)) nodes instead of O(b^m), reducing the effective branching factor from b to about √b. With random ordering, the gain is smaller, around O(b^(3m/4)).

Practical ordering heuristics include trying captures first, trying moves that were best in previous searches (killer moves), and iterative deepening, where shallower searches inform the ordering of deeper ones.

Transposition Tables

The same position can arise through different move orders. Storing the evaluation of positions already seen in a hash table avoids searching them again, and can dramatically reduce search effort.

Closing Thought

Alpha-beta is pure gain: no approximation, just less wasted work. It remained the backbone of game-playing programs for decades, until Monte Carlo methods opened a different path for games like Go.
