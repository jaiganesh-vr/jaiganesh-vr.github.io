Markov and Hidden Markov Models

Machine Learning Sequence Models

May 31, 2025

Independent and identically distributed data is a convenient fiction, and sequences break it directly. Today's weather depends on yesterday's, and the next word depends on the last few. Markov models are the simplest useful way to represent this dependence.

The Markov Assumption

The chain rule lets us write any sequence probability exactly, but with a history that keeps growing. A first-order Markov model assumes that the present screens off the past:

P(x₁, …, x_T) = P(x₁) · Π P(xₜ | xₜ₋₁)

For k discrete states, this is defined by an initial distribution and a transition matrix A, where Aᵢⱼ = P(xₜ = j | xₜ₋₁ = i). Each row of A sums to one.

Stationary Distributions

Propagating a distribution forward through a chain is matrix multiplication. Under mild conditions the chain forgets where it started and settles at a stationary distribution π, which is unchanged by another step:

π = π A

For example, take a two-state chain with A = [[0.9, 0.1], [0.5, 0.5]]. Solving gives π = (5/6, 1/6), and it spends five sixths of its time in the first state. PageRank is this idea applied to the web graph, and Markov chain Monte Carlo builds chains on purpose to have a chosen stationary distribution.

Language Models From Counting

An n-gram model is a Markov model over words. Learning is mostly counting, since the maximum likelihood estimate of a transition is:

Aᵢⱼ = count(i → j) / count(i)

Going beyond a few words of context makes the table too large and too sparse, and most sequences never appear in the training data. Smoothing helps, but the deeper limit of this kind of model is what motivated neural language models.

Hidden Markov Models

Often the state we care about is not directly observed. An HMM has hidden states zₜ that form a Markov chain, and each one emits an observation xₜ:

P(x, z) = P(z₁) · Π P(zₜ | zₜ₋₁) · Π P(xₜ | zₜ)

The observations themselves are not Markov. Since any past observation carries information about the hidden state, an HMM's observed sequence can have long dependencies, despite its simple structure.

Evaluation: The Forward Algorithm

The probability of the observations sums over exponentially many hidden paths. Dynamic programming reduces this to O(T k²). Define αₜ(j) = P(x₁:ₜ, zₜ = j), and recurse:

αₜ(j) = P(xₜ | zₜ = j) · Σᵢ αₜ₋₁(i) · Aᵢⱼ

Consider a casino that sometimes swaps a fair die for one that rolls six half the time. Given a run of rolls, this gives the sequence likelihood and the current chance the die is loaded. Rescaling at each step avoids numerical underflow. 

import numpy as np

def forward(obs, A, B, pi):
    """Returns the log-likelihood and the filtered state distribution."""
    alpha = pi * B[:, obs[0]]
    log_lik = np.log(alpha.sum())
    alpha /= alpha.sum()
    for x in obs[1:]:
        alpha = (alpha @ A) * B[:, x]
        log_lik += np.log(alpha.sum())
        alpha /= alpha.sum()
    return log_lik, alpha

A = np.array([[0.95, 0.05], [0.10, 0.90]])       # fair, loaded
B = np.array([[1/6] * 6, [0.1] * 5 + [0.5]])     # P(roll | state)
pi = np.array([0.5, 0.5])

for rolls in ([0, 3, 1, 2, 4, 2], [5, 5, 2, 5, 5, 5]):
    log_lik, belief = forward(rolls, A, B, pi)
    print(round(log_lik, 2), belief.round(2))

The second sequence, with its many sixes, leaves most of the belief on the loaded die.

Decoding and Learning

The Viterbi algorithm finds the single most probable path of hidden states, again by dynamic programming. Learning parameters is the harder part, since the states are never seen. The Baum-Welch algorithm is EM for HMMs:

  • E-step: run forward-backward to get the expected state occupancies and transitions.
  • M-step: re-estimate A and the emissions from those expected counts, just as if they were observed.

As with any EM, it finds a local optimum, so initialisation matters.

Limits

The first-order assumption means the state must carry everything that matters, which requires the number of states to grow exponentially with the amount of information remembered. RNNs and transformers avoid this by using distributed representations, and they have replaced HMMs in speech and language modelling. HMMs remain useful in bioinformatics and other settings with small data and clear state structure.

Closing Thought

Markov models tame long sequences by limiting memory, and hidden Markov models add back expressive power through what is unseen. Exact inference works here because the chain structure is simple, and when it is not, we turn to sampling.
