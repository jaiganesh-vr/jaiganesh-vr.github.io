Derivatives, Gradients and the Chain Rule

Mathematics Calculus

Feb 25, 2023

Training a model means adjusting many numbers to reduce a loss. Calculus tells us which way to adjust them. Only a small set of ideas is needed, and they all share one theme: locally, every smooth function looks linear.

The Derivative

The derivative measures how the output of a function responds to a small change in the input:

f′(x) = lim (h → 0) [ f(x + h) − f(x) ] / h

It is better thought of as the best linear approximation near a point:

f(x + h) ≈ f(x) + f′(x) · h

Partial Derivatives and the Gradient

With many inputs, a partial derivative varies one input while holding the others fixed. The gradient collects them all into a vector:

∇f(x) = ( ∂f/∂x₁, …, ∂f/∂xₙ )

For f(x, y) = x² + 3xy, the gradient is (2x + 3y, 3x). The linear approximation becomes a dot product:

f(x + h) ≈ f(x) + ∇f(x)ᵀh

The right-hand term is largest when h points along the gradient, by Cauchy-Schwarz. So the gradient points in the direction of steepest ascent, and it is perpendicular to the function's level sets.

Gradient descent is this fact, used repeatedly: step in the direction opposite to the gradient.

Useful Vector Results

A few identities cover most of the derivations in machine learning:

  • ∇ₓ (aᵀx) = a
  • ∇ₓ (xᵀAx) = (A + Aᵀ) x, or 2Ax for symmetric A
  • ∇_w ‖Xw − y‖² = 2Xᵀ(Xw − y)

Setting the last one to zero gives the normal equations of least squares.

The Jacobian

For a function from ℝⁿ to ℝᵐ, the derivatives form an m × n matrix, with Jᵢⱼ = ∂fᵢ/∂xⱼ. It is the matrix of the best linear approximation at a point, and a gradient is the special case of a function with a single output.

The Chain Rule

Derivatives of compositions multiply. In one variable:

d/dx f(g(x)) = f′(g(x)) · g′(x)

In many variables, the Jacobians multiply:

J_(f∘g)(x) = J_f(g(x)) · J_g(x)

The local linear approximation of a composition is the composition of the linear approximations. A neural network is one long composition, so its gradient is a long product of Jacobians.

Forward and Reverse Mode

Matrix multiplication is associative, so this product can be evaluated in either order.

  • Forward mode: multiply from the input side. It costs about one pass per input.
  • Reverse mode: multiply from the output side. It costs about one pass per output.

A loss has millions of inputs and a single output, so reverse mode gives the entire gradient at around the cost of one extra evaluation. This is backpropagation.

Checking Gradients

A numerical derivative makes a simple test for a hand-written gradient. The centred difference has much smaller error than the one-sided form: 

import numpy as np

def f(w, X, y):
    return ((X @ w - y)**2).sum()

def grad_f(w, X, y):
    return 2 * X.T @ (X @ w - y)

def numerical_grad(fn, w, eps=1e-6):
    grad = np.zeros_like(w)
    for i in range(len(w)):
        step = np.zeros_like(w)
        step[i] = eps
        grad[i] = (fn(w + step) - fn(w - step)) / (2 * eps)
    return grad

rng = np.random.default_rng(0)
X, y, w = rng.normal(size=(20, 3)), rng.normal(size=20), rng.normal(size=3)

analytic = grad_f(w, X, y)
numeric = numerical_grad(lambda w: f(w, X, y), w)
print(np.abs(analytic - numeric).max())  # very small

Closing Thought

The gradient gives a linear view of a function, and it is the cheapest useful piece of information we can get about one. Curvature comes next, since this tells us how far that linear view can be trusted.
