Inverse Substitution

Mathematics Calculus

Feb 15, 2025

Ordinary substitution spots an inner function, u = g(x), and replaces it with a simple variable. Inverse substitution works the other way around. It replaces x with a function of a new variable, which seems to make things more complicated but can remove a square root entirely.

The Method

Set x = g(u), so dx = g′(u) du. Rewrite everything in terms of u, then integrate:

∫ f(x) dx = ∫ f(g(u)) g′(u) du

g needs to be invertible on the relevant interval, so that the answer can be converted back to x. It is also where these substitutions get their name, since the new variable is an inverse function of x: u = g⁻¹(x).

The Three Trigonometric Cases

Each one uses a Pythagorean identity to change a sum or difference of squares into a perfect square:

  • √(a² − x²): let x = a sin θ, so a² − x² = a² cos² θ.
  • √(a² + x²): let x = a tan θ, so a² + x² = a² sec² θ.
  • √(x² − a²): let x = a sec θ, so x² − a² = a² tan² θ.

Choose the substitution whose identity makes the square root disappear.

Example: The Area of a Circle

A quarter of a circle of radius a has area:

∫₀ᵃ √(a² − x²) dx

Let x = a sin θ, so dx = a cos θ dθ and √(a² − x²) = a cos θ. The limits change too: x = 0 becomes θ = 0, and x = a becomes θ = π/2. Therefore:

∫₀^(π/2) a² cos² θ dθ = a² · π/4

The average of cos² over a quarter turn is 1/2, which gives the last step. Multiplying by four yields πa², the area of a circle.

Example: A Familiar Result

This method also explains an integral that is usually just memorised. For 1 / (1 + x²), let x = tan θ, so dx = sec² θ dθ. The denominator becomes sec² θ, and everything cancels:

∫ dx / (1 + x²) = ∫ dθ = θ + C = arctan x + C

Getting Back to x

An indefinite integral has to return to x. A right triangle does the conversion. In the next example, x = tan θ means the opposite side is x and the adjacent side is 1, so the hypotenuse is √(1 + x²).

Take:

∫ dx / ( x² √(1 + x²) )

Let x = tan θ. Then dx = sec² θ dθ and √(1 + x²) = sec θ:

∫ sec² θ dθ / (tan² θ · sec θ) = ∫ cos θ / sin² θ dθ = −1 / sin θ + C

From the triangle, sin θ = x / √(1 + x²). So the result is:

−√(1 + x²) / x + C

Checking the Results

For a definite integral, convert the limits instead of returning to x. Numerical integration is a quick way to catch sign errors or a wrong triangle: 

import numpy as np

def midpoint(f, a, b, n=1_000_000):
    dx = (b - a) / n
    return (f(a + dx * (np.arange(n) + 0.5)) * dx).sum()

print(midpoint(lambda x: np.sqrt(1 - x**2), 0, 1), np.pi / 4)

f = lambda x: 1 / (x**2 * np.sqrt(1 + x**2))
F = lambda x: -np.sqrt(1 + x**2) / x
print(midpoint(f, 1, 2), F(2) - F(1))

Completing the Square

A general quadratic can be brought into one of these forms. For example:

x² + 4x + 5 = (x + 2)² + 1

Substitute u = x + 2 first, and then u = tan θ, so that:

∫ dx / (x² + 4x + 5) = arctan(x + 2) + C

A Few Cautions

  • Sign of the square root: √(cos² θ) = |cos θ|. It is positive for θ in [−π/2, π/2], which is the range that the substitution x = a sin θ should use.
  • Keep the differential: forgetting to replace dx by g′(u) du is the most common mistake.
  • Simple substitution first: ∫ x √(1 − x²) dx looks like a trigonometric problem, but u = 1 − x² is much quicker.
  • Not always elementary: even after substituting, some integrals have no closed form.

Closing Thought

Inverse substitution makes the integrand look more complicated in order to reveal structure. Like a good change of coordinates, the point is to move to a variable in which the problem is simple. Letting a separate variable do the work is also a useful way of describing curves.
