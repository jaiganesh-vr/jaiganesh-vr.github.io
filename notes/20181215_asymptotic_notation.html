Asymptotic Notation

Algorithms Analysis

Dec 15, 2018

Comparing algorithms by measuring running time on a particular machine tells you little about how they behave on bigger inputs. Asymptotic notation describes how running time grows with input size n, ignoring constant factors and lower-order terms.

Why Ignore Constants

An algorithm taking 100n steps eventually beats one taking n², no matter how much faster the second one's machine is. For large n, growth rate dominates everything else.

Asymptotic analysis asks how cost scales, not how fast a single run is.

Big-Theta: Tight Bounds

f(n) = Θ(g(n)) if there are positive constants c₁, c₂ and n₀ such that:

0 ≤ c₁·g(n) ≤ f(n) ≤ c₂·g(n) for all n ≥ n₀

f grows at the same rate as g, up to constant factors. For example, 3n² + 10n + 5 = Θ(n²): beyond some point, the n² term dominates and the whole expression stays between two multiples of n².

Big-O: Upper Bounds

f(n) = O(g(n)) if there are positive constants c and n₀ such that 0 ≤ f(n) ≤ c·g(n) for all n ≥ n₀.

Big-O says f grows no faster than g. It is an upper bound, so it is technically true that 3n = O(n²), even though it is not tight. In everyday use, people often write O when they mean Θ.

Big-Omega: Lower Bounds

f(n) = Ω(g(n)) if there are positive constants c and n₀ such that 0 ≤ c·g(n) ≤ f(n) for all n ≥ n₀.

Big-Omega says f grows at least as fast as g. A useful theorem ties the three together: f(n) = Θ(g(n)) exactly when f(n) = O(g(n)) and f(n) = Ω(g(n)).

Little-o and Little-omega

  • o(g(n)): strictly slower growth. 2n = o(n²), but 2n² ≠ o(n²).
  • ω(g(n)): strictly faster growth. n² = ω(n).

Common Growth Rates

From slowest to fastest:

  • Θ(1): constant, such as array indexing.
  • Θ(lg n): logarithmic, such as binary search.
  • Θ(n): linear, such as scanning a list.
  • Θ(n lg n): such as merge sort and heapsort.
  • Θ(n²): quadratic, such as insertion sort in the worst case.
  • Θ(2ⁿ): exponential, such as trying every subset.

Worst, Best and Average Case

Asymptotic notation describes functions, and an algorithm can have different functions for different cases. Insertion sort is Θ(n²) in the worst case and Θ(n) in the best case. Saying its running time is O(n²) is correct for every input.

Closing Thought

Asymptotic notation is the vocabulary of algorithm analysis. It strips away details that change from machine to machine and keeps the one thing that decides whether an algorithm can handle large inputs.
