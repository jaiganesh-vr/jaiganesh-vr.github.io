The Master Method for Solving Recurrences

Algorithms Analysis

Jul 06, 2019

Divide-and-conquer algorithms produce recurrences describing their running time. The master method solves a large class of them almost mechanically, without drawing recursion trees each time.

The Form

The master method applies to recurrences of the form:

T(n) = a·T(n/b) + f(n)

where a ≥ 1 and b > 1 are constants. The algorithm splits a problem of size n into a subproblems of size n/b, and spends f(n) time dividing and combining.

The Key Comparison

Everything depends on comparing f(n) with n^(log_b a). That quantity is the total work at the leaves of the recursion tree: there are a^(log_b n) = n^(log_b a) leaves.

The question is which dominates: the work at the leaves, or the work at the root.

The Three Cases

  • Case 1: if f(n) = O(n^(log_b a − ε)) for some ε > 0, the leaves dominate, and T(n) = Θ(n^(log_b a)).
  • Case 2: if f(n) = Θ(n^(log_b a)), the work is spread evenly over the levels, and T(n) = Θ(n^(log_b a) · lg n).
  • Case 3: if f(n) = Ω(n^(log_b a + ε)) for some ε > 0, and a·f(n/b) ≤ c·f(n) for some c < 1, the root dominates, and T(n) = Θ(f(n)).

The extra condition in case 3, called the regularity condition, holds for most functions encountered in practice.

Worked Examples

  • Merge sort: T(n) = 2T(n/2) + n. Here n^(log₂ 2) = n, which matches f(n). Case 2 gives Θ(n lg n).
  • Binary search: T(n) = T(n/2) + 1. Here n^(log₂ 1) = n⁰ = 1, which matches f(n). Case 2 gives Θ(lg n).
  • T(n) = 9T(n/3) + n: n^(log₃ 9) = n², which grows polynomially faster than n. Case 1 gives Θ(n²).
  • T(n) = 3T(n/4) + n lg n: n^(log₄ 3) ≈ n^0.79, smaller than n lg n, and regularity holds. Case 3 gives Θ(n lg n).
  • Strassen's algorithm: T(n) = 7T(n/2) + n². n^(log₂ 7) ≈ n^2.81 dominates. Case 1 gives Θ(n^(lg 7)).

Where It Does Not Apply

The cases leave gaps. T(n) = 2T(n/2) + n lg n has f(n) larger than n, but not polynomially larger, so neither case 2 nor case 3 applies. Its solution is Θ(n lg² n), found with a recursion tree or an extended version of the theorem.

Recurrences with unequal subproblem sizes, like T(n) = T(n/3) + T(2n/3) + n, also fall outside the method. The substitution method, guessing a bound and proving it by induction, works for these.

Closing Thought

The master method compresses a recursion tree into a single comparison. Most divide-and-conquer algorithms can be analysed in a line once you know which of the three cases applies.
