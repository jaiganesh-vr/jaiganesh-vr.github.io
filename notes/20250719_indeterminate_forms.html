Indeterminate Forms and L'Hôpital's Rule

Mathematics Calculus

Jul 19, 2025

What is 0/0 as a limit? It might be anything, and that is the point. When numerator and denominator race toward zero, the answer depends on which gets there faster. Limits like this are called indeterminate, and a small set of tools handles nearly all of them.

Why They Are Indeterminate

All three of these have the form 0/0 as x goes to 0, yet each has a different value:

  • x² / x goes to 0.
  • x / x goes to 1.
  • x / x² grows without bound in size.

So the form tells us nothing about the value. The full list of indeterminate forms is:

0/0, ∞/∞, 0 · ∞, ∞ − ∞, 1^∞, 0⁰, ∞⁰

Some limits look like these and are not. A limit of the form 0^∞ goes to 0, and ∞ + ∞ goes to ∞. Checking the form before reaching for a rule avoids many errors.

L'Hôpital's Rule

If f and g both tend to 0, or both tend to ±∞, then:

lim f(x) / g(x) = lim f′(x) / g′(x)

as long as the right side exists. Near a point where both vanish, each is approximated by its tangent line, f(x) ≈ f′(a)(x − a) and g(x) ≈ g′(a)(x − a). The factors of (x − a) cancel, which leaves the ratio of derivatives.

Near the limit, the ratio of two functions is the ratio of how fast they change.

Note that you differentiate the top and bottom separately. It is not the quotient rule.

Examples

Apply the rule, repeating as needed:

lim (x → 0) sin x / x = lim cos x / 1 = 1

lim (x → 0) (1 − cos x) / x² = lim sin x / 2x = lim cos x / 2 = 1/2

lim (x → ∞) x² / eˣ = lim 2x / eˣ = lim 2 / eˣ = 0

Reshaping Other Forms

The rule needs a ratio, so convert first.

Product forms, 0 · ∞: move one factor to the denominator. For x ln x as x goes to 0 from the right:

lim ln x / (1/x) = lim (1/x) / (−1/x²) = lim (−x) = 0

Difference forms, ∞ − ∞: combine over a common denominator.

Exponent forms, 1^∞, 0⁰ and ∞⁰: take the logarithm. Compute the limit of ln y, then exponentiate. For y = xˣ as x goes to 0 from the right, ln y = x ln x tends to 0, as just shown, so y tends to e⁰ = 1.

The same approach gives the famous limit for e. With y = (1 + 1/n)ⁿ, we have ln y = n ln(1 + 1/n), which tends to 1, so y tends to e. A base shrinking toward 1 and an exponent growing without limit balance exactly at this number.

A Ranking of Growth

Repeated use of the rule establishes a ranking as x goes to ∞, for any constants p > 0 and a > 1:

ln x ≪ xᵖ ≪ aˣ ≪ x!

Any exponential eventually overtakes any power, and any power eventually overtakes the logarithm. This is why the ranking is so useful in the analysis of algorithms: an O(n log n) method beats an O(n²) one at scale. Here, the factorial is only defined at integers, but the ordering holds along them.

Misuses

  • Not actually indeterminate: at x = 0, (x² + 1) / (x + 1) is just 1. Applying the rule anyway gives 2x / 1, which is 0, and that is wrong.
  • The limit of the ratio of derivatives may not exist: (x + sin x) / x tends to 1 as x goes to ∞, but the ratio of derivatives, 1 + cos x, oscillates. The rule does not then say anything about the original limit.
  • Circularity: using the rule for sin x / x is circular in a strict development, since the derivative of sin x is itself derived using that limit.

Numerical Trouble

Indeterminate forms are also a practical hazard, since computers evaluate them with finite precision. As x shrinks, 1 − cos x loses all of its accuracy, because cos x rounds to exactly 1: 

import numpy as np

for x in (1e-2, 1e-5, 1e-8, 1e-10):
    naive = (1 - np.cos(x)) / x**2
    stable = 2 * np.sin(x / 2)**2 / x**2
    print(f"{x:.0e}  {naive:.10f}  {stable:.10f}")

The stable form uses the identity 1 − cos x = 2 sin²(x/2), which avoids subtracting two nearly equal numbers. Library functions such as expm1 and log1p exist for this same reason, and they are frequently used in machine learning code.

Closing Thought

Indeterminate forms are not undefined answers, but incomplete questions. The value depends on the rates of the two competing quantities, and it comes out once those rates are compared. The same kind of limit makes it possible to integrate over regions that are infinitely long.
