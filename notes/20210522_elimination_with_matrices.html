Elimination With Matrices

Mathematics Linear Algebra

May 22, 2021

Elimination is the method nearly every linear solver is built on. It is the school technique of subtracting one equation from another, carried out systematically, and writing it with matrices shows why it works and what it costs.

The Goal

We want to solve Ax = b. A triangular system is easy, because the last equation has one unknown, the one above it has two, and so on. Elimination turns A into an upper triangular matrix U, without changing the solutions.

A Worked Example

Take this system:

x + 2y + z = 2

3x + 8y + z = 12

4y + z = 2

Written as a matrix, with b attached as an extra column:

[ 1 2 1 | 2 ], [ 3 8 1 | 12 ], [ 0 4 1 | 2 ]

The first pivot is the 1 in the top left corner. Subtracting 3 times row 1 from row 2 clears the entry below it, and row 3 already has a zero there:

[ 1 2 1 | 2 ], [ 0 2 −2 | 6 ], [ 0 4 1 | 2 ]

The next pivot is the 2 in row 2. Subtracting 2 times row 2 from row 3 finishes the job:

[ 1 2 1 | 2 ], [ 0 2 −2 | 6 ], [ 0 0 5 | −10 ]

The pivots are 1, 2 and 5. The number subtracted at each step, here 3 and 2, is called the multiplier, and it equals the entry to clear divided by the pivot.

Back Substitution

Now solve from the bottom up:

  • 5z = −10, so z = −2.
  • 2y − 2z = 6, so y = 1.
  • x + 2y + z = 2, so x = 2.

Each Step Is a Matrix

A row operation is itself a matrix multiplication. Subtracting 3 times row 1 from row 2 is multiplication on the left by an identity matrix with one extra entry:

E₂₁ = [[1, 0, 0], [−3, 1, 0], [0, 0, 1]]

The whole process is then one product:

E₃₂ E₂₁ A = U

Elimination is a sequence of simple matrices applied to A from the left.

Multiplying on the left acts on rows, while multiplying on the right acts on columns. Keeping this straight makes the rest of matrix algebra much easier to follow.

When It Breaks Down

A pivot must be nonzero, because we divide by it. There are two kinds of trouble:

  • Temporary: a zero appears in the pivot position, but there is a nonzero entry below it. Exchanging the rows fixes this.
  • Permanent: there is no nonzero entry available. The matrix is singular, and there are either no solutions or infinitely many.

Exchanges also matter for accuracy. A very small pivot produces huge multipliers that magnify rounding errors, so practical solvers choose the largest available entry in the column as the pivot. This is known as partial pivoting. 

import numpy as np

def solve(A, b):
    A = A.astype(float)
    b = b.astype(float)
    n = len(A)
    for k in range(n):
        # Partial pivoting: bring up the largest entry in this column
        p = k + np.argmax(np.abs(A[k:, k]))
        if A[p, k] == 0:
            raise ValueError("matrix is singular")
        A[[k, p]], b[[k, p]] = A[[p, k]], b[[p, k]]
        for i in range(k + 1, n):
            m = A[i, k] / A[k, k]
            A[i, k:] -= m * A[k, k:]
            b[i] -= m * b[k]
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (b[i] - A[i, i + 1:] @ x[i + 1:]) / A[i, i]
    return x

A = np.array([[1, 2, 1], [3, 8, 1], [0, 4, 1]])
b = np.array([2, 12, 2])
print(solve(A, b))   # [ 2.  1. -2.]

The Cost

Clearing the first column of an n × n matrix takes about n² operations. The remaining columns work on smaller and smaller matrices, and the sum comes to about n³/3 operations. Back substitution takes only about n²/2 operations. So nearly all of the work is in the elimination, and doubling the size of a system makes it about eight times as expensive.

Closing Thought

Elimination looks like bookkeeping, yet each step is a matrix, and the multipliers that seem to be thrown away along the way are worth keeping. Saving them gives one of the most useful factorisations in numerical computing.
