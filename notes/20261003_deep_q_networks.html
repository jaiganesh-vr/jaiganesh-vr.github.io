Function Approximation and Deep Q-Networks

Artificial Intelligence Reinforcement Learning

Oct 03, 2026

Tabular reinforcement learning stores one value per state-action pair. Real problems have far too many states for that, and an agent must generalise: a situation it has never seen should be valued like similar situations it has. Function approximation provides that generalisation.

Approximating Q

Instead of a table, Q-values are computed by a parameterised function, Q(s, a; θ). Early approaches used linear functions of hand-designed features. Learning adjusts θ to reduce the temporal-difference error, much like supervised learning toward a moving target.

The payoff is huge: an approximator with a few thousand parameters can represent values for an astronomically large state space.

Deep Q-Networks

DQN, introduced around 2013 to 2015, used a convolutional neural network to approximate Q directly from raw screen pixels. A single architecture and set of hyperparameters learned to play dozens of Atari games, many at human level or better.

The network learned its own features from pixels, instead of relying on features designed by hand.

Why Naive Combination Fails

Combining Q-learning with a neural network is unstable out of the box:

  • Consecutive experiences are highly correlated, while neural network training assumes roughly independent samples.
  • The target depends on the same network being trained, so every update moves the target too.

The combination of function approximation, bootstrapping from estimates, and off-policy learning is known as the deadly triad, because it can make values diverge.

The Stabilising Tricks

  • Experience replay: store transitions in a buffer and train on random mini-batches from it. This breaks correlations and reuses each experience many times.
  • Target network: compute targets with a separate copy of the network that is updated only periodically, so the target stays still between updates.
  • Reward clipping and careful preprocessing: keep the scale of learning signals consistent across games.

Improvements That Followed

  • Double DQN: reduces overestimation by separating action selection from evaluation in the target.
  • Dueling networks: estimate state value and action advantages separately.
  • Prioritised replay: sample surprising transitions more often.

Beyond Value-Based Methods

Policy gradient and actor-critic methods learn the policy directly and handle continuous actions more naturally. Reinforcement learning from feedback, used to fine-tune modern language models, builds on these same foundations.

Closing Thought

Deep Q-Networks connected classical reinforcement learning to deep learning. The ideas in these notes, from search and MDPs to Q-learning, are still visible inside the learning systems built today.
