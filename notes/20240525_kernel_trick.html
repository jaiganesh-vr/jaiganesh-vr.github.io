The Kernel Trick

Machine Learning Kernel Methods

May 25, 2024

Linear models are well understood and easy to fit, but limited to linear boundaries. The kernel trick gives them nonlinear power by working in a richer feature space without ever explicitly going there.

Feature Maps and Their Cost

Data that is not linearly separable often becomes separable after a mapping φ(x). For example, points inside and outside a circle can be split by a plane once x₁² and x₂² are added as features. The trouble is that the number of features can explode. All degree-3 monomials of 1,000 inputs number over 160 million.

The Observation

Many algorithms touch the data only through dot products between pairs of points. Suppose we could compute φ(x)ᵀφ(z) directly and cheaply, without building φ. Then we would not need φ at all:

k(x, z) = φ(x)ᵀφ(z)

Take two-dimensional inputs and k(x, z) = (xᵀz)². Expanding it:

(x₁z₁ + x₂z₂)² = x₁²z₁² + 2x₁x₂z₁z₂ + x₂²z₂²

This is a dot product of the feature vectors φ(x) = (x₁², √2·x₁x₂, x₂²). We got the result in that three-dimensional space while computing only a two-dimensional dot product and a square.

The kernel gives the answer in feature space at the cost of a calculation in input space.

Common Kernels

  • Linear: k(x, z) = xᵀz.
  • Polynomial: k(x, z) = (xᵀz + c)ᵈ, which includes all monomials up to degree d.
  • Gaussian (RBF): k(x, z) = exp(−‖x − z‖² / 2ℓ²), whose feature space is infinite-dimensional.

The RBF kernel works as a similarity measure. It is 1 for identical points and decays with distance, at a rate controlled by the length scale ℓ. If ℓ is too small the model memorises the data, and if it is too large the model is too smooth.

What Makes a Kernel Valid

A function is a valid kernel if and only if, for any set of points, the Gram matrix K with Kᵢⱼ = k(xᵢ, xⱼ) is symmetric and positive semi-definite. This is Mercer's condition, and it guarantees that some feature space exists. Valid kernels can be combined: sums, products and positive multiples of kernels are again kernels. Kernels can also be defined on strings, graphs and other non-vector objects, as long as this condition holds.

Kernelising an Algorithm

The representer theorem says that for many regularised objectives the optimal solution is a weighted sum over training points:

f(x) = Σᵢ αᵢ k(xᵢ, x)

So we can learn α, one number per example, instead of a weight per feature. Applying this to ridge regression gives a closed form:

α = (K + λI)⁻¹ y 

import numpy as np

def rbf(A, B, length=0.2):
    d2 = ((A[:, None] - B[None, :])**2).sum(axis=2)
    return np.exp(-d2 / (2 * length**2))

def kernel_ridge(X, y, lam=0.01):
    alpha = np.linalg.solve(rbf(X, X) + lam * np.eye(len(X)), y)
    return lambda X_new: rbf(X_new, X) @ alpha

rng = np.random.default_rng(0)
X = rng.uniform(0, 1, (80, 1))
y = np.sin(6 * X[:, 0]) + rng.normal(0, 0.1, 80)

predict = kernel_ridge(X, y)
grid = np.linspace(0, 1, 5)[:, None]
print(predict(grid).round(2), np.sin(6 * grid[:, 0]).round(2))

A linear method, with one line changed, has fitted a sine wave.

The Cost

The trick moves the cost from the number of features to the number of examples. The Gram matrix has n² entries, and solving with it is O(n³), so exact kernel methods get hard past perhaps tens of thousands of points. Prediction also requires going through stored training points. Random Fourier features and the Nyström method offer approximations, and they are the usual way of scaling up.

Kernels and Neural Networks

A kernel fixes the features in advance, while a neural network learns them from data. On images and text, learned features have proved much stronger. Still, there are deep connections: certain infinitely wide networks behave like kernel machines, through the neural tangent kernel.

Closing Thought

The kernel trick is an algebraic observation that greatly extends linear methods. Its most famous beneficiary is the support vector machine, where the dual form of the problem depends on the data only through dot products.
