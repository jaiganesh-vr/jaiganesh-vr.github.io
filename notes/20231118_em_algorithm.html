The EM Algorithm

Machine Learning Latent Variable Models

Nov 18, 2023

Many models are easy to fit if we know some missing piece of information, and hard to fit otherwise. Expectation-maximisation handles this situation by alternating between guessing the missing piece and fitting the model as if the guess were right.

The Problem With Latent Variables

Let x be observed data and z unobserved latent variables. Maximum likelihood requires summing over z:

log P(x | θ) = log Σ_z P(x, z | θ)

The log of a sum does not break apart, and the parameters become coupled. If z were known, however, the log would sit on the joint directly, and the problem would often have a closed-form solution.

Gaussian Mixtures

A mixture of k Gaussians is the standard example. Each point comes from one hidden component:

P(x) = Σₖ πₖ N(x; μₖ, Σₖ)

If we knew each point's component, we could fit each Gaussian on its own points. If we knew the Gaussians, we could work out where each point likely came from. EM alternates between these.

  • E-step: compute responsibilities, the probability that component k generated point i: rᵢₖ = πₖ N(xᵢ; μₖ, Σₖ) / Σⱼ πⱼ N(xᵢ; μⱼ, Σⱼ)
  • M-step: refit each component using weighted averages, with Nₖ = Σᵢ rᵢₖ.

The M-step updates are the usual estimates, weighted by responsibility:

πₖ = Nₖ / n

μₖ = (1 / Nₖ) Σᵢ rᵢₖ xᵢ

Σₖ = (1 / Nₖ) Σᵢ rᵢₖ (xᵢ − μₖ)(xᵢ − μₖ)ᵀ 

import numpy as np

def gaussian(x, mu, var):
    return np.exp(-(x - mu)**2 / (2 * var)) / np.sqrt(2 * np.pi * var)

def em_gmm(x, k=2, steps=100, seed=0):
    rng = np.random.default_rng(seed)
    pi = np.full(k, 1 / k)
    mu = rng.choice(x, k, replace=False)
    var = np.full(k, x.var())
    for _ in range(steps):
        # E-step: responsibilities, one row per point
        r = pi * gaussian(x[:, None], mu, var)
        r /= r.sum(axis=1, keepdims=True)
        # M-step: weighted estimates
        n_k = r.sum(axis=0)
        pi = n_k / len(x)
        mu = (r * x[:, None]).sum(axis=0) / n_k
        var = (r * (x[:, None] - mu)**2).sum(axis=0) / n_k
    return pi, mu, var

rng = np.random.default_rng(1)
x = np.concatenate([rng.normal(-2, 0.5, 300), rng.normal(3, 1.0, 700)])
print([v.round(2) for v in em_gmm(x)])

Why It Works

For any distribution q over z, the log-likelihood splits in two:

log P(x | θ) = E_q[ log P(x, z | θ) − log q(z) ] + KL( q(z) ‖ P(z | x, θ) )

The first term is a lower bound, because the KL divergence is never negative.

  • E-step: set q to the posterior over z. The KL becomes zero and the bound touches the true likelihood.
  • M-step: maximise the bound over θ. The bound rises, and so does the likelihood, while the KL opens up again.

Each iteration builds a bound that touches the likelihood at the current parameters, then climbs it.

The log-likelihood therefore never goes down, which also provides a useful check when debugging an implementation.

What Can Go Wrong

  • Local optima: EM converges to a stationary point, which depends on the starting values. Restart several times or initialise with k-means, and keep the best result.
  • Singularities: a component can collapse onto one point, with its variance going to zero and the likelihood to infinity. Add a small floor to the variance or use a prior.
  • Speed: convergence is often quick at first and slow near the end.
  • Choosing k: the likelihood always improves with more components, so compare models with a criterion such as BIC or with held-out likelihood.

k-Means as a Limit

Take a mixture with equal weights and shared spherical covariance εI, and let ε shrink to zero. Responsibilities become hard assignments to the nearest centre, and the algorithm becomes k-means. So k-means is EM without any uncertainty about assignment, and it cannot model clusters of different shape or size.

Beyond Mixtures

The same pattern fits hidden Markov models, where it is known as the Baum-Welch algorithm, as well as factor analysis, topic models and data with missing values. If the E-step posterior is intractable, it can be approximated, which leads to variational inference.

Closing Thought

EM turns a hard problem into a loop of two easy ones. It is a good example of a recurring trick in machine learning: adding hidden structure to a problem, which sounds like making it harder, can make it far simpler.
