All-Pairs Shortest Paths

Algorithms Graphs

Aug 23, 2025

Sometimes we need the shortest distance between every pair of vertices, for example to build a distance table between all cities on a map. The output alone is a V × V matrix, so the question is how efficiently it can be filled.

Running Single-Source Algorithms V Times

The obvious approach runs a single-source algorithm from every vertex:

  • Dijkstra from each vertex: O(V(V + E) lg V) with a binary heap, if all weights are non-negative.
  • Bellman-Ford from each vertex: O(V²E), which is O(V⁴) on dense graphs. Too slow.

Floyd-Warshall

Floyd-Warshall uses dynamic programming. Number the vertices 1 to n. Let d_k[i][j] be the length of the shortest path from i to j using only vertices 1 to k as intermediate stops. Either the best path avoids vertex k, or it goes through k exactly once:

d_k[i][j] = min( d_(k−1)[i][j], d_(k−1)[i][k] + d_(k−1)[k][j] ) 

def floyd_warshall(n, weight):
    INF = float("inf")
    d = [[0 if i == j else weight.get((i, j), INF) for j in range(n)]
         for i in range(n)]
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d

Three nested loops give Θ(V³) time, with tiny constants and Θ(V²) space, since the table can be updated in place. It handles negative edges, and a negative value on the diagonal reveals a negative cycle.

Allow one more intermediate vertex at a time, and update every pair.

Transitive Closure

A variation answers a simpler question: can i reach j at all? Replacing min and plus with logical OR and AND gives the transitive closure of a graph in the same Θ(V³) time.

Johnson's Algorithm

For sparse graphs with negative edges, Johnson's algorithm does better. It reweights every edge to make all weights non-negative without changing which paths are shortest, then runs Dijkstra from each vertex.

  • Add a new vertex s with zero-weight edges to every vertex.
  • Run Bellman-Ford from s to get a value h(v) for each vertex.
  • Reweight each edge (u, v) as w(u, v) + h(u) − h(v), which is never negative.
  • Run Dijkstra from every vertex, then undo the reweighting.

Every path between the same two vertices shifts by the same amount, so shortest paths are preserved. The total time is O(V² lg V + VE) with a Fibonacci heap.

Choosing an Algorithm

  • Dense graphs: Floyd-Warshall, for its simplicity and small constants.
  • Sparse graphs, non-negative weights: Dijkstra from every vertex.
  • Sparse graphs, negative weights: Johnson's algorithm.

Closing Thought

All-pairs shortest paths shows dynamic programming at its cleanest. Floyd-Warshall solves a seemingly complex problem with three loops and a single comparison.
