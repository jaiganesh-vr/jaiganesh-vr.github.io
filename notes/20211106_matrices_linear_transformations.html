Matrices as Linear Transformations

Mathematics Linear Algebra

Nov 06, 2021

A matrix is usually presented as a grid of numbers with a strange multiplication rule. That rule makes sense once you see a matrix as a function that takes in a vector and transforms space.

Columns Are the Whole Story

Multiplying a vector by a matrix produces a linear combination of the matrix's columns:

Ax = x₁a₁ + x₂a₂ + … + xₙaₙ

The columns show where the basis vectors land. The vector (1, 0) goes to the first column and (0, 1) goes to the second. Every other vector follows by linearity. For example:

A = [[0, −1], [1, 0]]

sends (1, 0) to (0, 1) and (0, 1) to (−1, 0). This is a 90-degree rotation.

To read a matrix, ask where it sends the basis vectors.

Linear Maps

A map is linear when it preserves addition and scaling: f(ax + by) = a·f(x) + b·f(y). Grid lines stay straight and evenly spaced, and the origin stays put. Rotations, reflections, scalings and shears all qualify, and every such map corresponds to some matrix.

Multiplication Is Composition

AB means applying B and then A. Applying the map to each column of B explains the rule for matrix multiplication, and also why the following hold:

  • Order matters: AB is generally not BA. Rotating and then scaling is not the same as scaling and then rotating.
  • Sizes must fit: the output of B must be the input of A.
  • Associativity: (AB)C = A(BC), because composition of functions does not care about grouping.

A neural network without activation functions is just a composition of linear maps, so it collapses to one single matrix. That is why nonlinearities are essential. 

import numpy as np

rotate = np.array([[0, -1], [1, 0]])    # 90 degrees anticlockwise
scale = np.array([[2, 0], [0, 1]])      # stretch x by 2

v = np.array([1, 1])
print(rotate @ (scale @ v))             # [-1  2]
print((rotate @ scale) @ v)             # same: composition
print((scale @ rotate) @ v)             # [-2  1]: order matters

Rank

The set of all outputs Ax is the column space, and its dimension is the rank. It says how many dimensions survive. A 3 × 3 matrix of rank 2 flattens space onto a plane. The vectors sent to zero form the null space, and the two dimensions always add up to the size of the input:

rank(A) + nullity(A) = n

Determinants

The determinant is the factor by which a square matrix scales volume. A determinant of 2 doubles areas, and a negative one also flips orientation. A determinant of 0 means that space has been flattened into a lower dimension, so the matrix has lost information.

Inverses

If nothing has been flattened, the map can be undone by the inverse, with A⁻¹A = I. A square matrix is invertible exactly when it has full rank, which is the same as having a determinant other than zero and a null space containing only zero.

In practice, computing an explicit inverse is rarely a good idea. To solve Ax = b, use a factorisation, as in numpy.linalg.solve, which is both faster and more numerically stable.

A Note on the Transpose

Swapping rows and columns gives Aᵀ. It lets a matrix change sides in a dot product:

(Ax)ᵀy = xᵀ(Aᵀy)

This identity comes up constantly in derivations. It is what produces the XᵀX in least squares.

Closing Thought

Seen as transformations, the rules of matrix algebra stop being arbitrary. Most vectors change direction under a matrix, but a few special ones do not, and they reveal its deeper structure.
