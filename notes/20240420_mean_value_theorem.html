The Mean Value Theorem

Mathematics Calculus

Apr 20, 2024

Most facts in calculus that feel obvious, such as "a function with positive derivative is increasing", actually need proof. Nearly all of them rest on one theorem linking a function's overall change to its derivative at some point.

The Statement

If f is continuous on [a, b] and differentiable on (a, b), then there is some c strictly between a and b where:

f′(c) = ( f(b) − f(a) ) / (b − a)

The right side is the slope of the chord between the endpoints. So somewhere the tangent is parallel to that chord.

If you drive 100 km in one hour, then at some moment your speedometer read exactly 100 km/h.

For example, f(x) = x² on [0, 2] has chord slope (4 − 0) / 2 = 2. Since f′(x) = 2x, the promised point is c = 1.

Rolle's Theorem

Start with the special case where f(a) = f(b). The theorem then says there is a point where f′(c) = 0. A continuous function on a closed interval attains a maximum and a minimum. If both of these are at the endpoints, then the function is constant, and f′ is zero everywhere. Otherwise an extremum lies in the interior, and the derivative there is zero.

The general theorem follows by tilting. Subtract the chord from f:

g(x) = f(x) − f(a) − [ (f(b) − f(a)) / (b − a) ] · (x − a)

Then g(a) = g(b) = 0, and Rolle's theorem gives a point where g′(c) = 0. This is exactly the statement we want.

Why the Conditions Matter

  • Differentiability: |x| on [−1, 1] has chord slope 0, but f′ is never 0. It is ±1 everywhere and undefined at the corner.
  • Continuity: a function that jumps can have a chord of any slope, with a derivative that does not match it anywhere.

The theorem also says nothing about where c is or how many such points there are, only that at least one exists. That is sufficient for everything that follows. 

def find_c(f, df, a, b, tol=1e-10):
    """Bisection on f'(x) minus the chord slope, assuming a sign change."""
    slope = (f(b) - f(a)) / (b - a)
    lo, hi = a, b
    while hi - lo > tol:
        mid = (lo + hi) / 2
        if (df(lo) - slope) * (df(mid) - slope) <= 0:
            hi = mid
        else:
            lo = mid
    return (lo + hi) / 2

print(round(find_c(lambda x: x**2, lambda x: 2 * x, 0, 2), 6))         # 1.0
print(round(find_c(lambda x: x**3, lambda x: 3 * x**2, 0, 3), 6))      # 1.732051

What It Gives Us

Rearranged, the theorem reads f(b) − f(a) = f′(c)(b − a). That connects derivative information to function values, which is how each of these follows:

  • Sign of the derivative: if f′ > 0 throughout an interval, then f(b) − f(a) > 0 whenever b > a, so f is increasing.
  • Constant functions: if f′ = 0 everywhere on an interval, then f(b) = f(a) for every a and b, so f is constant.
  • Antiderivatives: if F′ = G′, then F − G has derivative zero, so F and G differ by a constant. That is why the "+ C" in integration is the whole story.

Bounds Without Calculation

The theorem also turns a bound on f′ into a bound on f, even when c is unknown. Since |cos c| ≤ 1, we get:

|sin b − sin a| ≤ |b − a|

The same method gives a quick estimate of √101. With f(x) = √x on [100, 101], we have:

√101 − 10 = 1 / (2√c), with 100 < c < 101

Since 10 < √c < 11, this places √101 between 10 + 1/22 and 10 + 1/20, or between 10.045 and 10.05. The true value is about 10.0499.

The general form of this, |f(b) − f(a)| ≤ L |b − a|, is Lipschitz continuity. It is used across numerical analysis and machine learning to reason about how far a function can move for a given input change.

Closing Thought

The mean value theorem rarely gets used to compute anything directly, because it does not locate c. Its job is to convert knowledge about derivatives into knowledge about functions. Its largest payoff is the fundamental theorem of calculus.
