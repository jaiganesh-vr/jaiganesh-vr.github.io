Constraint Satisfaction Problems

Artificial Intelligence CSP

Jan 15, 2022

In standard search, states are black boxes: the algorithm only knows how to generate successors and test for goals. Constraint satisfaction problems open the box. States have a factored structure, and that structure enables powerful general-purpose techniques.

The Formulation

A CSP consists of:

  • Variables: X₁, …, Xₙ.
  • Domains: the set of allowed values for each variable.
  • Constraints: relations specifying allowed combinations of values.

A solution is a complete assignment, a value for every variable, that satisfies all constraints.

Example: Map Colouring

Colour each region of Australia red, green or blue so that no neighbouring regions share a colour.

  • Variables: WA, NT, SA, Q, NSW, V, T.
  • Domains: {red, green, blue} for each.
  • Constraints: WA ≠ NT, WA ≠ SA, NT ≠ SA, and so on for each border.

The constraint graph has a node per variable and an edge per binary constraint, which makes the structure of the problem visible.

Kinds of Constraints

  • Unary: restrict one variable, such as SA ≠ green.
  • Binary: relate two variables, such as SA ≠ WA.
  • Global: involve many variables, such as Alldiff, which requires all of them to be different.
  • Preferences: soft constraints that should be satisfied if possible, turning the problem into constraint optimization.

More Examples

  • Sudoku: 81 variables, domains 1 to 9, Alldiff constraints on each row, column and box.
  • Scheduling: tasks are variables, start times are values, constraints express precedence and resource limits.
  • Timetabling: classes, rooms and time slots.

Many real problems are naturally described by what must be true, not by how to find it.

Why CSPs Help

Because the algorithm understands the constraints, it can do much better than blind search:

  • It can detect that a partial assignment already violates a constraint and stop exploring it.
  • It can propagate constraints, shrinking domains of other variables before searching.
  • It can use general heuristics that work across all CSPs.

Ruling out a single colour for one region in map colouring can eliminate huge numbers of complete assignments at once.

Closing Thought

Constraint satisfaction is a declarative way to think about problems: state the variables and rules, and let general algorithms find solutions. The next note looks at how those algorithms work.
