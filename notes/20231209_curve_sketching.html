Curve Sketching

Mathematics Calculus

Dec 09, 2023

Before there were plotting tools, drawing a graph required understanding the function. It is still a good exercise, because it connects the numbers from derivatives with a mental picture of what a function does.

What Each Derivative Tells You

  • f′ > 0: the function is increasing.
  • f′ < 0: the function is decreasing.
  • f″ > 0: the function is concave up, shaped like a cup.
  • f″ < 0: the function is concave down, shaped like a cap.

Two kinds of special points follow. A critical point is where f′ = 0 or f′ does not exist. An inflection point is where the concavity actually changes.

A Recipe

  • Plot easy points: intercepts, and any points that are easy to calculate.
  • Find the ends: behaviour as x goes to ±∞, and near any point where the function blows up.
  • Find f′: locate critical points and plot them, then mark which way the function goes between them.
  • Find f″: locate inflection points and mark concavity.
  • Connect it all: combine this into a smooth curve, and check that it is all consistent.

Example: A Cubic

Take f(x) = x³ − 3x + 1. The ends go to ±∞ as x goes to ±∞. The first derivative is:

f′(x) = 3x² − 3 = 3(x − 1)(x + 1)

So the critical points are x = −1 and x = 1, where f takes the values 3 and −1. Looking at the signs of f′:

  • x < −1: f′ > 0, so rising.
  • −1 < x < 1: f′ < 0, so falling.
  • x > 1: f′ > 0, so rising.

Rising then falling makes x = −1 a local maximum, and falling then rising makes x = 1 a local minimum. The second derivative, f″(x) = 6x, is zero at x = 0, which changes sign there, so (0, 1) is an inflection point. It lies right between the two critical points, as it does for all cubics of this kind.

Example: A Rational Function

Take f(x) = (x + 1) / (x + 2). The denominator vanishes at x = −2, so there is a vertical asymptote there. As x goes to ±∞, the function approaches y = 1, a horizontal asymptote. The intercepts are at x = −1 and y = 1/2. The derivatives are:

f′(x) = 1 / (x + 2)²

f″(x) = −2 / (x + 2)³

f′ is always positive, so the function rises on both sides of the asymptote. There are no critical points. Concavity changes at x = −2, but this is not an inflection point, because the function is not defined there.

Check f′ where it is defined. A function can be increasing on each piece while still falling from one piece to the next.

Indeed f(−3) = 2 but f(0) = 1/2. It is increasing on each interval separately, though not across the asymptote. 

def describe(f, xs, h=1e-5):
    """Numerical signs of f' and f'' at each sample point."""
    for x in xs:
        d1 = (f(x + h) - f(x - h)) / (2 * h)
        d2 = (f(x + h) - 2 * f(x) + f(x - h)) / h**2
        rise = "rising" if d1 > 0 else "falling"
        bend = "cup" if d2 > 0 else "cap"
        print(f"x = {x:5.1f}  f = {f(x):6.2f}  {rise:8}{bend}")

describe(lambda x: x**3 - 3 * x + 1, [-2, -0.5, 0.5, 2])

Traps

  • f′(a) = 0 does not imply an extremum: x³ has a flat point at 0, but it keeps rising.
  • f″(a) = 0 does not imply an inflection: x⁴ has f″(0) = 0, but it is a cup on both sides and 0 is a minimum.
  • Corners count: |x| has a minimum at 0, where f′ does not exist.
  • Second derivative test: when f′(a) = 0, f″(a) > 0 means a minimum and f″(a) < 0 means a maximum. If f″(a) = 0, the test says nothing.

Maxima and Minima

To find the absolute largest and smallest values on a closed interval, compare the function at its critical points and its endpoints. The endpoints are easily missed. On [0, 3], our cubic has its largest value at the endpoint x = 3, where f = 19, and not at any critical point.

Closing Thought

A sketch is a compact summary of the function's behaviour. The critical points it reveals can often be found exactly in textbook examples, while real equations usually need a numerical way of finding where a function crosses zero.
