Uninformed Search Strategies

Artificial Intelligence Search

Sep 07, 2019

Uninformed, or blind, search strategies know nothing about the problem beyond its definition. They cannot tell whether one state is closer to the goal than another. They differ only in the order they expand nodes.

Breadth-First Search

Breadth-first search expands the shallowest unexpanded node first, using a FIFO queue as the frontier.

  • Complete when the branching factor is finite.
  • Optimal when all step costs are equal.
  • Time and space O(b^d).

Memory is the real problem. With a branching factor of 10, searching to depth 12 would need terabytes. BFS is practical only for small problems.

Uniform-Cost Search

Uniform-cost search expands the node with the lowest path cost g(n), using a priority queue. It is optimal for any positive step costs, and it is essentially Dijkstra's algorithm applied to search.

Depth-First Search

Depth-first search expands the deepest node first, using a LIFO stack.

  • Not complete in infinite spaces, since it can descend forever.
  • Not optimal.
  • Space only O(b·m), linear in depth.

That modest memory use is its great advantage.

BFS finds the shortest path but needs exponential memory. DFS needs little memory but may never return.

Depth-Limited and Iterative Deepening

Depth-limited search is DFS with a cutoff depth. Iterative deepening runs depth-limited search with limits 0, 1, 2 and so on until a goal appears.

It looks wasteful, because shallow levels are searched many times. But in a tree most nodes are at the deepest level, so the repeated work is small. Iterative deepening combines BFS's completeness and optimality for unit costs with DFS's linear memory. It is the preferred uninformed method when the search space is large and the solution depth is unknown.

Bidirectional Search

Running one search forward from the start and another backward from the goal, and stopping when they meet, reduces the cost from b^d to roughly 2·b^(d/2). It requires being able to compute predecessors of states, which is not always possible.

Closing Thought

Uninformed search is the baseline. Its exponential cost is exactly why the next step, guiding search with knowledge about the problem, matters so much.
