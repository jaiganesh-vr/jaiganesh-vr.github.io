Red-Black Trees

Algorithms Data Structures

Aug 20, 2022

A plain binary search tree can degrade into a linked list. Red-black trees add a colour bit to each node and a few rules, which together keep the tree approximately balanced and guarantee O(lg n) operations.

The Five Properties

  • Every node is either red or black.
  • The root is black.
  • Every leaf, represented by a shared NIL sentinel, is black.
  • If a node is red, both its children are black.
  • For each node, every path from it down to a leaf contains the same number of black nodes.

The number of black nodes on such a path, not counting the node itself, is its black-height.

Why the Height Is Bounded

The fourth rule means red nodes can never appear twice in a row on a path. The fifth rule means all paths have the same number of black nodes. So the longest path, alternating red and black, is at most twice as long as the shortest, all black.

From this one can prove that a red-black tree with n internal nodes has height at most 2 lg(n + 1).

The tree is never perfectly balanced, but it is never badly unbalanced either.

Rotations

Insertions and deletions can violate the properties. They are repaired with recolouring and rotations, local operations that change the tree's shape while preserving the BST ordering. 

  x                y
 / \    left      / \
a   y   ---->    x   c
   / \   rotate  / \
  b   c         a   b

A rotation changes a constant number of pointers, so it takes O(1) time.

Insertion

A new node is inserted as in an ordinary BST and coloured red, which preserves black-heights. The only possible violation is a red node with a red parent. The fix-up walks up the tree:

  • Uncle is red: recolour parent and uncle black, grandparent red, and continue from the grandparent.
  • Uncle is black, node is an inner child: rotate to turn it into the outer case.
  • Uncle is black, node is an outer child: rotate at the grandparent and recolour. The tree is now valid.

At most two rotations are needed per insertion, plus O(lg n) recolourings.

Deletion

Deletion is more involved, because removing a black node reduces some black-heights. Its fix-up has four cases, but it also needs at most three rotations and runs in O(lg n).

Where They Are Used

Red-black trees implement ordered maps and sets in many standard libraries, including C++'s std::map and Java's TreeMap, and appear in operating system schedulers and memory managers. AVL trees are more strictly balanced, giving faster lookups but more rotations on updates.

Closing Thought

Red-black trees achieve guaranteed logarithmic performance with very little extra information: one bit per node. A handful of local repairs keeps the whole tree in shape.
