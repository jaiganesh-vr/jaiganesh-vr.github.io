Support Vector Machines

Machine Learning Kernel Methods

Sep 07, 2024

When two classes can be separated by a line, infinitely many lines do it. A support vector machine picks the one that stays furthest from both classes. This idea, once combined with kernels, made SVMs a dominant method for much of the 2000s.

The Margin

Label classes y = ±1 and take a linear classifier f(x) = wᵀx + b. The distance from a point to the boundary is |f(x)| / ‖w‖. w and b can be rescaled freely, so fix the scale by requiring f(x) = ±1 on the closest points. The gap between the classes then has width:

margin = 2 / ‖w‖

Maximising the margin is the same as minimising ‖w‖:

minimise ½ ‖w‖² subject to yᵢ (wᵀxᵢ + b) ≥ 1 for all i

This is a convex quadratic program, so it has a single global solution.

Soft Margins

Real data overlaps. Slack variables ξᵢ ≥ 0 let points violate the margin at a cost:

minimise ½ ‖w‖² + C Σ ξᵢ subject to yᵢ (wᵀxᵢ + b) ≥ 1 − ξᵢ

C sets the tradeoff. A large C penalises violations heavily and risks overfitting. A small C accepts violations and gives a wider margin.

The Hinge Loss View

At the optimum each slack is as small as allowed, so the constraints can be folded into an unconstrained objective:

min Σ max(0, 1 − yᵢ f(xᵢ)) + (λ/2) ‖w‖², with λ = 1/C

So a linear SVM is L2-regularised empirical risk minimisation with the hinge loss. It differs from logistic regression only in the loss function. The hinge is exactly zero for points beyond the margin, while the logistic loss is never quite zero. It can be trained directly with subgradient descent. 

import numpy as np

def fit_svm(X, y, lam=0.01, steps=20000, seed=0):
    """Pegasos: stochastic subgradient descent on the hinge loss."""
    rng = np.random.default_rng(seed)
    X = np.hstack([X, np.ones((len(X), 1))])  # intercept as a feature
    w = np.zeros(X.shape[1])
    for t in range(1, steps + 1):
        i = rng.integers(len(X))
        lr = 1 / (lam * t)
        w *= 1 - lr * lam
        if y[i] * (w @ X[i]) < 1:
            w += lr * y[i] * X[i]
    return w

rng = np.random.default_rng(1)
X = np.vstack([rng.normal(-2, 1, (100, 2)), rng.normal(2, 1, (100, 2))])
y = np.repeat([-1, 1], 100)
w = fit_svm(X, y)
print((np.sign(X @ w[:2] + w[2]) == y).mean())

The Dual Problem

Using Lagrange multipliers on the constraints gives an equivalent problem over one variable αᵢ per example:

maximise Σ αᵢ − ½ Σᵢ Σⱼ αᵢ αⱼ yᵢ yⱼ xᵢᵀxⱼ

subject to 0 ≤ αᵢ ≤ C and Σ αᵢ yᵢ = 0

The weights are recovered as w = Σ αᵢ yᵢ xᵢ. The dual has two useful properties.

Support Vectors

The optimality conditions force αᵢ = 0 for every point strictly outside the margin. Only points on the margin or violating it, the support vectors, have a nonzero αᵢ and contribute to the solution.

Delete any other training point and refit, and the boundary does not move.

The Kernel Connection

The data appears in the dual only through dot products xᵢᵀxⱼ, so we can replace them with a kernel k(xᵢ, xⱼ). Predictions become:

f(x) = Σᵢ αᵢ yᵢ k(xᵢ, x) + b

The result is a maximum margin hyperplane in feature space, seen as a nonlinear boundary in the original space. Because many αᵢ are zero, only the support vectors need to be stored.

Practical Notes

  • Scale features: both margins and RBF kernels depend on distance.
  • Tune C and the kernel width together: a logarithmic grid search with cross-validation is standard.
  • Probabilities: SVMs output scores, not probabilities. Platt scaling fits a logistic function on top if probabilities are needed.
  • Scale: kernel SVMs take roughly quadratic to cubic time in n. For large datasets use linear SVMs, or approximate kernels.

Closing Thought

The SVM rests on a geometric intuition, a convex problem and a neat algebraic trick. Neural networks have overtaken it on perceptual data, but it is still a strong tool for small and medium tabular datasets, and the ideas of margins and duality are widely useful.
