Propositional Logic

Artificial Intelligence Logic

Jul 02, 2022

Knowledge-based agents represent what they know as sentences in a formal language and reason with them to decide what to do. Propositional logic is the simplest such language, and it introduces ideas that carry over to every richer logic.

Syntax

Atomic sentences are proposition symbols, like P or Raining, each standing for a fact that is either true or false. Complex sentences are built with connectives:

  • ¬P: not P.
  • P ∧ Q: P and Q.
  • P ∨ Q: P or Q.
  • P ⇒ Q: if P then Q.
  • P ⇔ Q: P if and only if Q.

Semantics

A model assigns true or false to every proposition symbol. The truth of any sentence in a model is computed from its parts using truth tables.

The implication P ⇒ Q is false only when P is true and Q is false. It is true whenever P is false, which feels odd at first: "if pigs fly then the moon is cheese" is true. Implication in logic does not claim any causal connection.

Entailment

A knowledge base KB entails a sentence α, written KB ⊨ α, if α is true in every model in which KB is true.

Entailment means: whenever what I know is true, this must also be true.

The simplest way to check entailment is model checking: enumerate all models, and verify that α holds in each one where KB holds. With n symbols there are 2ⁿ models, so this is exponential, but it is sound and complete.

Validity and Satisfiability

  • A sentence is valid if it is true in all models, like P ∨ ¬P. Valid sentences are also called tautologies.
  • A sentence is satisfiable if it is true in at least one model.
  • A sentence is unsatisfiable if it is true in no model.

These connect directly to entailment: KB ⊨ α exactly when KB ∧ ¬α is unsatisfiable. This is proof by contradiction, and it is the basis of resolution theorem proving.

The Wumpus World

The classic teaching example is a cave with pits and a monster. The agent perceives a breeze near pits and a stench near the monster, and uses sentences like B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁) to infer which squares are safe without ever visiting them.

Limits

Propositional logic cannot express general rules compactly. Saying that every square with a breeze has a neighbouring pit requires a separate sentence for every square. That limitation motivates first-order logic.

Closing Thought

Propositional logic gives agents a precise way to know things and to derive new facts with certainty. Its ideas of models and entailment are the foundation for all logical reasoning in AI.
