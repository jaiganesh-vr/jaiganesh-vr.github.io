Single-Source Shortest Paths

Algorithms Graphs

Mar 01, 2025

Navigation apps, network routing and many planning problems need the shortest paths from one starting point to every other vertex in a weighted graph. Several algorithms solve this, depending on what the edge weights look like.

Relaxation

Every algorithm here keeps an estimate d[v] of the shortest distance to each vertex, starting at infinity, with d[source] = 0. The basic step is relaxing an edge (u, v) with weight w:

if d[u] + w < d[v], then d[v] ← d[u] + w

That is, check whether going through u gives a shorter path to v. The algorithms differ only in the order and number of relaxations.

Negative Weights and Cycles

Negative edge weights are allowed in some problems, such as currency arbitrage. But if a cycle has negative total weight and is reachable from the source, shortest paths are undefined: going around it again always reduces the cost.

Bellman-Ford

Bellman-Ford relaxes every edge V − 1 times. Since a shortest path has at most V − 1 edges, that is enough. A final pass checks whether any edge can still be relaxed; if so, there is a negative cycle.

It runs in O(VE) and handles negative weights.

Shortest Paths in a DAG

In a directed acyclic graph, relaxing edges in topological order gives correct distances in a single pass, in O(V + E), even with negative weights. This is the basis of critical path analysis in project scheduling.

Dijkstra's Algorithm

With non-negative weights, Dijkstra's algorithm is much faster. It repeatedly takes the unvisited vertex with the smallest distance estimate, which is then final, and relaxes its outgoing edges. 

import heapq

def dijkstra(graph, source):
    dist = {source: 0}
    heap = [(0, source)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue                     # stale entry
        for v, w in graph[u]:
            if d + w < dist.get(v, float("inf")):
                dist[v] = d + w
                heapq.heappush(heap, (d + w, v))
    return dist

With a binary heap it runs in O((V + E) lg V).

Dijkstra is greedy: once a vertex is the closest unvisited one, no later path can beat it, as long as no edge is negative.

A single negative edge breaks that guarantee, which is why Bellman-Ford remains necessary.

Choosing an Algorithm

  • Non-negative weights: Dijkstra.
  • Directed acyclic graph: topological-order relaxation.
  • Negative weights possible: Bellman-Ford, which also detects negative cycles.
  • Unweighted: plain breadth-first search.

Closing Thought

All shortest-path algorithms share one operation, relaxation. Their differences are about ordering it cleverly, and the right order depends entirely on what the weights can be.
