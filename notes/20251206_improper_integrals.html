Improper Integrals

Mathematics Calculus

Dec 06, 2025

The definite integral was defined for bounded functions on finite intervals. Yet many useful integrals go out to infinity or involve a function that blows up. An infinitely long region can still have finite area, and improper integrals make sense of this with a limit.

Infinite Limits

Replace the infinite endpoint with a finite one and take the limit:

∫ₐ^∞ f(x) dx = lim (R → ∞) ∫ₐᴿ f(x) dx

If that limit exists and is finite, the integral converges. Otherwise it diverges. For example:

∫₀^∞ e⁻ˣ dx = lim (R → ∞) (1 − e⁻ᴿ) = 1

So an infinitely long region has an area of exactly 1.

For an integral over the whole real line, split it at a point and require each side to converge separately. So ∫ x dx over the real line diverges, even though symmetric limits would give zero.

Infinite Integrands

If f blows up at an endpoint, approach it with a limit in the same way:

∫₀¹ dx / √x = lim (a → 0⁺) (2 − 2√a) = 2

If it blows up inside the interval, split the integral there. Ignoring this is a classic trap:

∫₋₁¹ dx / x² naively gives −2

A negative area from a positive integrand is impossible. Splitting at zero shows that each side diverges, so the integral has no finite value.

The p-Test

Powers of x provide the standard scale for what converges:

  • At infinity: ∫₁^∞ dx / xᵖ converges exactly when p > 1, and equals 1 / (p − 1).
  • Near zero: ∫₀¹ dx / xᵖ converges exactly when p < 1, and equals 1 / (1 − p).

At infinity, the function must fall fast enough. Near zero, it must rise slowly enough.

The borderline case p = 1 diverges in both, with ln x growing without limit, if very slowly. 

import numpy as np

def tail(p, R):
    """Exact integral of x^(-p) from 1 to R."""
    return np.log(R) if p == 1 else (R**(1 - p) - 1) / (1 - p)

for R in (1e2, 1e4, 1e8, 1e16):
    print(f"{R:.0e}", round(tail(2, R), 4), round(tail(1, R), 2), round(tail(0.5, R), 1))

With p = 2, it settles at 1. With p = 1, it creeps up forever, and with p = 1/2, it grows quickly.

Comparison

Most integrals cannot be computed exactly, but convergence can often still be settled by comparison. If 0 ≤ f(x) ≤ g(x) for large x:

  • If ∫ g converges, then ∫ f converges.
  • If ∫ f diverges, then ∫ g diverges.

For example, e^(−x²) ≤ e⁻ˣ for x ≥ 1, so ∫₁^∞ e^(−x²) dx converges without needing an antiderivative. There is also a limit version: if f / g tends to a positive constant, they converge or diverge together. So 1 / (x² + 5x + 1) converges at infinity, as it behaves like 1 / x².

Famous Results

  • The Gaussian integral: ∫₋∞^∞ e^(−x²) dx = √π. The usual proof squares the integral and switches to polar coordinates.
  • The gamma function: Γ(n) = ∫₀^∞ xⁿ⁻¹ e⁻ˣ dx, which extends the factorial, since Γ(n) = (n − 1)! for positive integers.
  • Gabriel's horn: revolving 1/x around the x-axis for x ≥ 1 gives a solid with volume π but infinite surface area. It could be filled with paint, but not painted.

Connection to Probability

Probability is full of improper integrals. A density must integrate to one, and normalising constants come from these results, which is where the √(2π) in the normal distribution comes from.

Moments are also improper integrals, and they may not converge. The Cauchy density is 1 / (π(1 + x²)). Its total area is 1, but its expected value involves x / (1 + x²), which behaves like 1/x at infinity. That diverges by the p-test, so the Cauchy distribution has no mean, and the law of large numbers does not apply to it.

Numerical Integration

Numerical methods cannot sample all the way to infinity, so they rely on a change of variable, such as x = 1/t or x = t / (1 − t), to convert the range to a finite interval. Singularities at endpoints need special quadrature rules too. Libraries like scipy.integrate.quad handle these cases, but it is still wise to check that an integral converges first, as a program may return a plausible value for one that does not.

Closing Thought

Improper integrals show that infinity alone does not make a quantity infinite. What counts is how quickly the terms shrink. A similar question arises for infinite sums, as with polynomial series, whose convergence depends on how quickly their terms fall.
