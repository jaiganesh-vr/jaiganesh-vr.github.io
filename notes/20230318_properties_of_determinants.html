Properties of Determinants

Mathematics Linear Algebra

Mar 18, 2023

The determinant is usually taught as a formula, which makes it look arbitrary. It is clearer to start from three simple properties. They define it completely, and every other fact about it follows from them.

The Three Defining Properties

  • Identity: det I = 1.
  • Exchange: swapping two rows reverses the sign of the determinant.
  • Linearity in each row: with all other rows held fixed, the determinant is a linear function of any one row.

The last one needs some care. It means that multiplying one row by t multiplies the determinant by t, and that the determinants of two matrices differing in only one row add. It does not mean det(A + B) = det A + det B, which is false in general.

Exactly one function satisfies all three. That function is the determinant.

What Follows

Each of these can be derived from the three above:

  • Equal rows give zero: swapping them leaves the matrix unchanged but flips the sign, so det = −det, which forces zero.
  • Elimination changes nothing: subtracting a multiple of one row from another leaves the determinant unchanged. By linearity, the change is a multiple of the determinant of a matrix with two equal rows.
  • A zero row gives zero: multiply that row by 0 and apply linearity.
  • Triangular matrices: the determinant is the product of the diagonal entries.
  • Singular matrices: det A = 0 exactly when A is singular, since elimination then produces a zero row.
  • Products: det(AB) = det(A) · det(B).
  • Transposes: det(Aᵀ) = det(A). So all of the rules for rows apply equally to columns.

A few useful results are immediate from the product rule: det(A⁻¹) = 1 / det(A), and scaling an n × n matrix gives det(2A) = 2ⁿ det(A), because each of the n rows contributes a factor of 2.

Computing a Determinant

These properties offer a good algorithm: reduce to a triangular matrix and multiply the pivots, while tracking the sign of the exchanges.

det A = ± (product of the pivots)

For [[1, 2], [3, 4]], subtracting 3 times row 1 from row 2 gives [[1, 2], [0, −2]], so the determinant is 1 · (−2) = −2. This agrees with the familiar formula ad − bc. 

import numpy as np

def det(A):
    A = A.astype(float)
    n, sign = len(A), 1.0
    for k in range(n):
        p = k + np.argmax(np.abs(A[k:, k]))
        if A[p, k] == 0:
            return 0.0
        if p != k:
            A[[k, p]] = A[[p, k]]
            sign = -sign                # an exchange flips the sign
        A[k + 1:, k:] -= np.outer(A[k + 1:, k] / A[k, k], A[k, k:])  # no change
    return sign * np.prod(np.diag(A))

A = np.array([[1, 2, 1], [3, 8, 1], [0, 4, 1]])
print(round(det(A), 10))                # 10.0
print(round(np.linalg.det(A), 10))      # 10.0

The Big Formula

Splitting each row by linearity, and throwing out the terms with a repeated column, leaves one term per permutation:

det A = Σ sign(σ) · a₁σ₁ · a₂σ₂ · … · aₙσₙ

Each term picks one entry from each row and each column. There are n! of them, so this is useless for computation at any real size: it has over 3 million terms at n = 10, and over 10²⁶ at n = 26. The elimination approach takes about n³/3 steps. The formula is still useful for theory, since it shows that the determinant is a polynomial in the entries.

Cofactors

Grouping those terms by the entries of one row gives cofactor expansion, which expresses a determinant through smaller determinants. It also leads to an explicit formula for the inverse, A⁻¹ = Cᵀ / det A, and Cramer's rule. These are of more theoretical interest than computational, but they do show plainly how a nearly singular matrix leads to a very large inverse.

A Caution

A small determinant does not mean a matrix is nearly singular. 0.1 · I in 10 dimensions has determinant 10⁻¹⁰ and is perfectly conditioned. Large matrices also commonly overflow or underflow the floating point range, which is why numerical code works with the log-determinant, as a sum of log pivots. Use the condition number, not the determinant, to judge whether a matrix is close to singular.

Closing Thought

Starting from three properties makes every rule about the determinant a short consequence rather than a separate fact. Its most important role comes up in the eigenvalue equation det(A − λI) = 0, which detects exactly when a matrix has been made singular.
