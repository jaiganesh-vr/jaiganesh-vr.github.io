L2 Regularization

Machine Learning Regularization

May 13, 2023

L2 regularisation is the most common way of controlling model complexity. It is easy to state and appears under several names: ridge regression, weight decay and Tikhonov regularisation. Each name reflects a different way of understanding the same operation.

The Objective

Add the squared size of the weights to the loss:

J(w) = ‖y − Xw‖² + λ ‖w‖²

λ sets the strength. At zero we recover ordinary least squares, and as it grows the weights shrink toward zero.

A Closed Form

Setting the gradient to zero gives a small change to the normal equations:

w = (XᵀX + λI)⁻¹ Xᵀy

Adding λ to the diagonal also makes the matrix invertible, even when features are perfectly correlated or there are more features than examples. 

import numpy as np

def ridge(X, y, lam):
    # Centre so the intercept is not penalised
    x_mean, y_mean = X.mean(axis=0), y.mean()
    Xc, yc = X - x_mean, y - y_mean
    d = X.shape[1]
    w = np.linalg.solve(Xc.T @ Xc + lam * np.eye(d), Xc.T @ yc)
    return w, y_mean - x_mean @ w

rng = np.random.default_rng(0)
X = rng.normal(size=(30, 20))
X[:, 1] = X[:, 0] + rng.normal(0, 0.01, 30)  # nearly duplicate feature
y = X[:, 0] + rng.normal(0, 0.5, 30)

for lam in (0.001, 1.0, 10.0):
    w, b = ridge(X, y, lam)
    print(lam, round(np.linalg.norm(w), 2))

The Bayesian View

Ridge is MAP estimation. Assume Gaussian noise with variance σ² and a Gaussian prior on each weight, N(0, τ²). The negative log posterior is the ridge objective, with:

λ = σ² / τ²

A strong prior (small τ²) or noisy data (large σ²) both call for more shrinkage. This also gives a principled alternative to cross-validation, since the evidence can be used to choose λ.

The Geometric View

Use the SVD, X = UDVᵀ. The ridge prediction is:

ŷ = Σⱼ uⱼ · ( dⱼ² / (dⱼ² + λ) ) · uⱼᵀy

Each direction in the data is scaled by a factor between 0 and 1. Directions with large singular values are almost untouched, and directions with small ones are heavily shrunk. These low-variance directions are where the data says little and where least squares is most unstable.

Ridge does not shrink everything evenly. It trusts directions in proportion to how much evidence the data provides for them.

Summing those factors gives the effective degrees of freedom, which falls from the number of features at λ = 0 toward zero as λ grows.

L2 and L1

The lasso replaces the penalty with λ‖w‖₁. L2 shrinks all weights smoothly but rarely sets any exactly to zero, and it spreads weight among correlated features. L1 produces sparse solutions by zeroing some of them entirely, at the cost of no closed form and less stable selection among correlated features. Elastic net combines the two.

Practical Details

  • Standardise features: the penalty depends on scale, and a feature with a small numeric range needs a large weight and gets penalised more for it.
  • Leave the intercept out: penalising it would make predictions depend on where the origin of y happens to be.
  • Choose λ by search: cross-validate over a logarithmic grid, such as 10⁻⁴ to 10⁴.

Weight Decay in Neural Networks

In gradient descent, the penalty multiplies the weights by a factor slightly below one on each step:

w ← (1 − ηλ) w − η ∇L(w)

Here λ is the coefficient of the penalty (λ/2)‖w‖². With plain SGD, weight decay and L2 are equivalent. With adaptive optimisers such as Adam they are not, since the penalty gradient gets rescaled along with the loss gradient. AdamW fixes this by applying the decay separately.

Closing Thought

A penalty, a prior and a filter on singular values turn out to be the same thing. Being able to switch between these views makes it much easier to see what λ is doing and how to set it.
