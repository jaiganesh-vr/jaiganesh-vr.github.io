Newton's Method for Finding Roots

Mathematics Calculus

Feb 10, 2024

Most equations have no solution you can write in closed form. Newton's method finds one numerically in a few steps, by repeatedly replacing a curve with its tangent line.

The Idea

We want a root of f, a value where f(x) = 0. Start with a guess x₀. The tangent line at that point is:

y = f(x₀) + f′(x₀)(x − x₀)

Solving for where this line crosses zero gives a better guess. Repeating this gives the method:

xₙ₊₁ = xₙ − f(xₙ) / f′(xₙ)

A curve is hard to solve, but a line is easy. So replace the curve with its tangent, solve, and repeat.

Example: Square Roots

To find √2, solve f(x) = x² − 2 = 0. Substituting into the formula gives a neat result:

xₙ₊₁ = ½ (xₙ + 2 / xₙ)

This is averaging a guess with 2 divided by that guess. Starting from x₀ = 1 gives:

  • x₁ = 1.5
  • x₂ = 1.41666…
  • x₃ = 1.41421568…
  • x₄ = 1.41421356237…

The true value is 1.41421356237…. Four steps give eleven correct decimal places. 

def newton(f, df, x, steps=6):
    for n in range(steps):
        x = x - f(x) / df(x)
        print(n + 1, x, abs(f(x)))
    return x

newton(lambda x: x**2 - 2, lambda x: 2 * x, 1.0)

Why It Is So Fast

Let eₙ = xₙ − r be the error at step n, where r is the root. Near r, a Taylor expansion of f shows that:

eₙ₊₁ ≈ ( f″(r) / 2f′(r) ) · eₙ²

The new error is proportional to the square of the old one. An error of 10⁻³ becomes about 10⁻⁶ and then 10⁻¹². So the number of correct digits roughly doubles with every step. This is quadratic convergence. Bisection, by comparison, gains only about one digit in every three or four steps.

How It Fails

The formula above shows when trouble comes. The speed depends on a good start and on f′ staying away from zero.

  • Flat spots: if f′(xₙ) is near zero, the tangent is nearly horizontal and the next guess shoots far away.
  • Cycles: for f(x) = x³ − 2x + 2, starting at 0 gives 1, then 0, and it repeats forever.
  • Divergence: for f(x) = x^(1/3), the formula becomes xₙ₊₁ = −2xₙ. Each step moves further from the root at 0, whatever the start.
  • Wrong root: with several roots, which one is found can depend very sensitively on the starting point.
  • Multiple roots: for f(x) = x², where f′ is also zero at the root, the formula gives xₙ₊₁ = xₙ / 2. It still works but the convergence is only linear.

Using It Reliably

Good solvers protect the fast local method from those failures.

  • Bracketing: keep an interval where f changes sign, and fall back to bisection if a Newton step leaves it. Brent's method is a common example.
  • Damping: take only part of the Newton step if the full step does not reduce |f|.
  • Secant method: replace f′ by a slope through the last two points, when the derivative is not available. It costs less per step, and it converges only a little more slowly, with an order of about 1.618.
  • Stopping: stop when both the step and |f(x)| are small, since a tiny value of f alone may not mean x is close to the root.

Everywhere in Computing

Hardware and math libraries use versions of it to compute square roots and even division. Solving for 1/a means finding a root of f(x) = 1/x − a, and Newton's method gives xₙ₊₁ = xₙ(2 − a xₙ), which requires only multiplication. So division can be done with no division at all.

The idea also extends to systems of equations, with the Jacobian in place of f′. Each step becomes a linear solve.

Closing Thought

Newton's method shows how far you can get by trusting a local linear approximation and correcting it often. Why that local information is reliable is a question about how a derivative relates to a function's overall change.
